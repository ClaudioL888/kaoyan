# 二、本范围核心知识、重点与易错点梳理【重点】

先给出总框架：

[
\boxed{
A\xi=\lambda\xi
\Longleftrightarrow
(\lambda E-A)\xi=0
\Longrightarrow
|\lambda E-A|=0
}
]

这是整个本范围最重要的起点。

随后核心问题变成：

[
\boxed{
\begin{array}{c}
\text{求特征值}\
\downarrow\
|\lambda E-A|=0
\end{array}
}
\quad\Longrightarrow\quad
\boxed{
\begin{array}{c}
\text{求特征向量}\
\downarrow\
(\lambda E-A)x=0
\end{array}
}
]

再进一步：

[
\boxed{
\text{有没有 }n\text{ 个线性无关特征向量}
\Longleftrightarrow
A\text{ 能否相似对角化}
}
]

---

# 1. 特征值与特征向量的定义

## 知识点

教材印刷P140，“特征值与特征向量的定义”：

> “设 (A) 是 (n) 阶矩阵，(\lambda) 是一个数，若存在 (n) 维非零列向量 (\xi)，使得 (A\xi=\lambda\xi)，则称 (\lambda) 是 (A) 的特征值，(\xi) 是 (A) 的对应于特征值 (\lambda) 的特征向量。”



### 怎么理解

(A\xi=\lambda\xi) 表示：

矩阵 (A) 作用在向量 (\xi) 上以后，**没有改变它所在的方向，只把它伸缩了 (\lambda) 倍**。

所以：

* (\lambda)：描述“缩放多少”；
* (\xi)：描述“不改变方向的特殊方向”。

### 最重要的条件

[
\boxed{\xi\ne0}
]

零向量永远不能叫特征向量。

因为若允许 (\xi=0)，则

[
A0=\lambda0
]

对任何 (\lambda) 都成立，特征值概念就失去意义。

### 怎么用

题目出现：

[
A\xi=\lambda\xi
]

几乎可以立刻做以下转换：

* 已知 (\xi)，求 (\lambda)：直接比较分量；
* 已知 (\lambda)，求 (\xi)：
  [
  (\lambda E-A)\xi=0;
  ]
* 已知若干组 (A\xi_i=\lambda_i\xi_i)，可以直接构造对角化矩阵。

典型题：1、3、5、8、9、16、20、21、22。

---

# 2. 特征值和特征向量的标准求法

教材P140：

> “求解具体型矩阵的特征值与特征向量，一般先用特征方程 (|\lambda E-A|=0) 求出 (\lambda)，再解齐次线性方程组 ((\lambda E-A)x=0)，求出特征向量。”



所以必须熟练掌握：

[
\boxed{|\lambda E-A|=0}
]

求出所有特征值后，对每一个 (\lambda_i)：

[
\boxed{(\lambda_iE-A)x=0}
]

求其基础解系。

若基础解系为

[
\xi_1,\ldots,\xi_s,
]

那么该特征值对应的**全部特征向量**为

[
\boxed{
k_1\xi_1+\cdots+k_s\xi_s,
\qquad
(k_1,\ldots,k_s)\ne(0,\ldots,0).
}
]

### 一个常见错误

基础解系里可以有零系数，但最终组合不能全部为零。

比如

[
x=k_1\xi_1+k_2\xi_2
]

表示特征向量时，应写

[
\boxed{k_1,k_2\text{ 不全为 }0}.
]

---

# 3. 特征多项式

教材P140称：

[
\boxed{|\lambda E-A|}
]

为特征多项式，

[
\boxed{|\lambda E-A|=0}
]

为特征方程。

对于 (n) 阶矩阵：

[
|\lambda E-A|
=============

(\lambda-\lambda_1)\cdots(\lambda-\lambda_n),
]

其中特征值按重数重复计算。

---

# 4. 迹和行列式与特征值的关系

这是本范围极高频的二级结论：

[
\boxed{
\operatorname{tr}A
=\lambda_1+\cdots+\lambda_n
}
]

[
\boxed{
|A|
=\lambda_1\lambda_2\cdots\lambda_n
}
]

第10、12、23题都直接使用。

### 怎么用

如果三阶矩阵已经知道两个特征值 (\lambda_1,\lambda_2)，第三个通常最快通过

[
\lambda_3
=========

\operatorname{tr}A-\lambda_1-\lambda_2
]

得到。

比重新展开三阶特征多项式稳定得多。

### 易错点

迹是**主对角线元素之和**：

[
\operatorname{tr}A=a_{11}+\cdots+a_{nn},
]

不是全部元素之和。

---

# 5. 每行元素之和相等

若

[
A
\begin{pmatrix}
1\1\\vdots\1
\end{pmatrix}
=============

s
\begin{pmatrix}
1\1\\vdots\1
\end{pmatrix},
]

也就是每行元素之和都为 (s)，则立即知道：

[
\boxed{s\text{ 是 }A\text{ 的一个特征值}}
]

且

[
\boxed{
(1,1,\ldots,1)^T
}
]

是对应特征向量。

这是第12题的第一突破口。

### 易错点

“每列元素之和为 (s)”时，

[
(1,\ldots,1)^TA=s(1,\ldots,1)^T
]

得到的是**左特征向量**关系；不能直接说 ((1,\ldots,1)^T) 是 (A) 的右特征向量。

不过 (A) 与 (A^T) 特征值相同，所以 (s) 仍然是特征值。

---

# 6. 不同特征值对应的特征向量线性无关

若

[
\lambda_1,\lambda_2,\ldots,\lambda_s
]

互不相同，对应非零特征向量

[
\xi_1,\ldots,\xi_s,
]

则

[
\boxed{\xi_1,\ldots,\xi_s\text{ 线性无关}}.
]

### 怎么用

这是“不同特征值很多 ⇒ 可对角化”的根本原因。

特别地，若 (n) 阶矩阵有 (n) 个互不相同的特征值：

[
\boxed{A\text{ 一定可以相似对角化}}.
]

典型题：7、11、14、18、22。

---

# 7. 同一特征值的特征向量可以线性组合

若

[
A\alpha=\lambda\alpha,
\qquad
A\beta=\lambda\beta,
]

那么

[
A(k_1\alpha+k_2\beta)
=====================

\lambda(k_1\alpha+k_2\beta).
]

因此只要

[
k_1\alpha+k_2\beta\ne0,
]

它仍是 (\lambda) 的特征向量。

### 但是不同特征值不能随便相加

若

[
A\alpha=\lambda_1\alpha,\qquad
A\beta=\lambda_2\beta,\qquad
\lambda_1\ne\lambda_2,
]

则一般

[
\alpha+\beta
]

**不是**特征向量。

第1、3、22题都在考这个区别。

---

# 8. 多项式矩阵 (f(A)) 的特征值

若

[
A\xi=\lambda\xi,
]

则

[
A^k\xi=\lambda^k\xi.
]

因此对于多项式

[
f(x)=a_0+a_1x+\cdots+a_mx^m,
]

有

[
\boxed{
f(A)\xi=f(\lambda)\xi
}
]

所以：

[
\boxed{
\lambda\text{ 是 }A\text{ 的特征值}
\Longrightarrow
f(\lambda)\text{ 是 }f(A)\text{ 的特征值}
}
]

且原特征向量 (\xi) 仍然可以使用。

典型：

[
A\xi=\lambda\xi
]

则

[
(2E-A)\xi=(2-\lambda)\xi.
]

这正是第1题。

---

# 9. 伴随矩阵的特征值

若 (A) 可逆，则

[
A^*=|A|A^{-1}.
]

若

[
A\xi=\lambda\xi,
]

则 (\lambda\ne0)，并有

[
A^{-1}\xi=\frac1\lambda\xi.
]

所以

[
\boxed{
A^*\xi
======

\frac{|A|}{\lambda}\xi
}
]

即：

[
\boxed{
A^*\text{ 对应特征值 }
\frac{|A|}{\lambda}
}
]

且特征向量仍为 (\xi)。

第5、9、21题都是这个结论。

---

# 10. 相似的定义及核心性质

若存在可逆矩阵 (P)，使

[
\boxed{
B=P^{-1}AP,
}
]

则称 (A,B) 相似。

当前教材PDF后续正文缺失，因此这里不冒充教材引用；下列结论在官方解析P126—137中被反复实际使用。

相似矩阵必有：

[
\boxed{
|\lambda E-A|=|\lambda E-B|
}
]

因此有相同：

[
\boxed{
\begin{array}{c}
\text{特征多项式}\
\text{特征值及重数}\
\operatorname{tr}\
\det\
\operatorname{rank}
\end{array}
}
]

但：

[
\boxed{
\text{特征值相同}\not\Rightarrow\text{矩阵相似}
}
]

官方解析在第14题后的特别提示就是：

> “相似必有相同的 (\lambda)，但 (\lambda) 相同不一定相似。”



这是非常高频的反向误用。

---

# 11. 相似时特征向量怎么变

若

[
B=P^{-1}AP,
\qquad
A\xi=\lambda\xi,
]

则

[
B(P^{-1}\xi)
============

# P^{-1}A\xi

\lambda P^{-1}\xi.
]

因此：

[
\boxed{
A\text{ 的特征向量 }\xi
\quad\longrightarrow\quad
B\text{ 的特征向量 }P^{-1}\xi
}
]

第5题直接考这一点。

---

# 12. 相似对角化的本质

所谓相似对角化，是存在可逆矩阵 (P)，使

[
\boxed{
P^{-1}AP
========

# \Lambda

\operatorname{diag}(\lambda_1,\ldots,\lambda_n).
}
]

设

[
P=(\xi_1,\ldots,\xi_n),
]

则

[
AP=P\Lambda
]

等价于

[
A\xi_i=\lambda_i\xi_i.
]

所以：

[
\boxed{
A\text{ 可相似对角化}
\iff
A\text{ 有 }n\text{ 个线性无关特征向量}
}
]

这是整个本范围第二重要结论。

---

# 13. (P) 的列和 (\Lambda) 的顺序必须一一对应

若

[
P=(\xi_1,\xi_2,\xi_3),
]

而

[
A\xi_1=2\xi_1,\quad
A\xi_2=-\xi_2,\quad
A\xi_3=3\xi_3,
]

则

[
P^{-1}AP
========

\begin{pmatrix}
2&0&0\
0&-1&0\
0&0&3
\end{pmatrix}.
]

若把 (P) 改成

[
(\xi_3,\xi_1,\xi_2),
]

对角线也必须改为

[
(3,2,-1).
]

第3、16题专门考这个。

---

# 14. 特征向量可以任意非零倍缩放

若

[
A\xi=\lambda\xi,
]

则对 (k\ne0)：

[
A(k\xi)=\lambda(k\xi).
]

因此：

[
\xi,\quad -2\xi,\quad 100\xi
]

都代表同一个特征方向。

所以构造 (P) 时：

* 可以换倍数；
* 同一特征子空间内可以换基；
* 同一特征值的列可以交换顺序。

但不能把**不同特征值的特征向量相加以后**继续当作其中一个原特征值的特征向量。

第3题就是典型辨析。

---

# 15. 代数重数和几何重数【核心难点】

假设 (\lambda_0) 是特征方程的 (k) 重根，则：

[
k=\text{代数重数}.
]

而

[
(\lambda_0E-A)x=0
]

基础解系中的向量个数为：

[
\boxed{
n-r(\lambda_0E-A)
}
]

即几何重数。

永远有：

[
\boxed{
1\le
\text{几何重数}
\le
\text{代数重数}
}
]

---

## 可对角化最重要的判别

若 (\lambda) 的代数重数是 (k)，则要想可对角化，必须有：

[
\boxed{
n-r(\lambda E-A)=k
}
]

也就是：

[
\boxed{
r(\lambda E-A)=n-k.
}
]

官方解析第11题后专门强调：

> “讨论矩阵是否能相似对角化，不必具体计算出特征向量，在有重特征值时，只需计算 (r(\lambda E-A))，讨论线性无关的特征向量个数是否和重数相等即可。”



这句话应该重点记。

---

# 16. 三阶矩阵二重特征值的快速判别

若三阶矩阵 (\lambda_0) 是二重特征值：

要有两个线性无关特征向量：

[
3-r(\lambda_0E-A)=2
]

所以

[
\boxed{
r(\lambda_0E-A)=1.
}
]

若

[
r(\lambda_0E-A)=2,
]

则只有一个线性无关特征向量，因此不能对角化。

第2、7、10、11、15题反复出现。

---

# 17. 三重特征值的情况

三阶矩阵若只有一个三重特征值 (\lambda)：

* 3个线性无关特征向量：
  [
  r(\lambda E-A)=0,
  ]
  此时实际上
  [
  A=\lambda E;
  ]
* 2个线性无关特征向量：
  [
  r(\lambda E-A)=1;
  ]
* 1个线性无关特征向量：
  [
  r(\lambda E-A)=2.
  ]

第2题用的就是第二种。

---

# 18. 实对称矩阵的特殊性质【极重要】

若

[
A^T=A,
]

则：

### 性质1

全部特征值都是实数。

### 性质2

不同特征值对应的特征向量相互正交。

### 性质3

必可相似对角化，而且可以正交对角化：

[
\boxed{
Q^TAQ=\Lambda,
\qquad
Q^{-1}=Q^T.
}
]

### 性质4

即使有重特征值，也一定能在对应特征子空间中取到足够多的正交特征向量。

第7、12、13、23题使用。

---

# 19. 实对称矩阵 + 多项式关系

若

[
p(A)=O
]

且 (A) 实对称，则对任意特征值 (\lambda)：

[
p(\lambda)=0.
]

因为特征值必须是实数，所以只需保留 (p(x)) 的实根。

例如第13题：

[
A+A^2+\frac12A^3=O.
]

对应：

[
\lambda+\lambda^2+\frac12\lambda^3=0,
]

即

[
\lambda(\lambda^2+2\lambda+2)=0.
]

后一个因式的根：

[
-1\pm i
]

不是实数。

因此所有特征值只能是

[
0.
]

又由于 (A) 实对称、必可对角化，所以

[
\boxed{A=O}.
]

### 极易错

若没有“实对称”条件：

[
\text{所有特征值均为0}
]

**不能推出**

[
A=O.
]

例如非零幂零矩阵的所有特征值也都是0。

---

# 20. 实对称矩阵求 (A^n)

若

[
Q^TAQ=\Lambda,
]

则

[
A=Q\Lambda Q^T.
]

所以

[
\boxed{
A^n=Q\Lambda^nQ^T.
}
]

这是第12、23题核心。

如果

[
\Lambda=\operatorname{diag}(1,1,3),
]

则

[
\Lambda^n
=========

\operatorname{diag}(1,1,3^n).
]

无需直接乘 (A^n)。

---

# 21. 已知一整组特征向量反求矩阵

若有 (n) 个线性无关特征向量：

[
A\xi_i=\lambda_i\xi_i
]

令

[
P=(\xi_1,\ldots,\xi_n),
]

则

[
AP=P\Lambda.
]

所以

[
\boxed{
A=P\Lambda P^{-1}.
}
]

这比设 (A) 有 (n^2) 个未知数再逐项解方程高效得多。

---

# 22. 初等变换一般不保持特征值

这是本范围极容易犯的错误。

单独进行：

[
\text{初等行变换}
]

或者：

[
\text{初等列变换}
]

一般**不保持特征值**。

只有当它们恰好组合成：

[
\boxed{
P^{-1}AP
}
]

时，才是相似变换，才保持特征值。

第6题故意设计为：

* 先做一次列变换；
* 再做与它互逆的一次行变换；

最终构成

[
P^{-1}AP.
]

所以才能直接读特征值。

---

# 23. (0) 特征值与秩

[
0\text{ 是 }A\text{ 的特征值}
\iff
|A|=0
\iff
A\text{ 不可逆}.
]

对于 (n) 阶矩阵：

[
\dim N(A)=n-r(A)
]

就是特征值0对应的几何重数。

例如三阶：

[
r(A)=1
]

则

[
\dim N(A)=2.
]

所以0至少有两个线性无关特征向量，从而：

[
\boxed{
0\text{ 的代数重数至少为2}
}
]

但可能是2，也可能是3。

这正是第17题。

# 24. (AB) 与 (BA)

若 (A) 可逆：

[
A^{-1}(AB)A=BA.
]

因此：

[
\boxed{
AB\sim BA.
}
]

若 (A) 不可逆，则一般不能这么做。

第14题特别说明：

[
\boxed{
\text{一般的 }A,B
\text{ 不保证 }AB\sim BA.
}
]

官方解析给反例，使

[
r(AB)=0,\qquad r(BA)=1,
]

而相似矩阵秩必须相同，因此不相似。

# 25. 特征多项式的求根技巧

教材P142专门提醒：

> “用 (|\lambda E-A|=0) 求出全部的 (\lambda) 是起步，也是关键。”

并给出多项式求根的快速观察：

对

[
f(\lambda)
=a_n\lambda^n+\cdots+a_1\lambda+a_0,
]

若：

[
a_0=0,
]

则

[
\lambda=0
]

是根；

若：

[
a_n+\cdots+a_1+a_0=0,
]

则

[
\lambda=1
]

是根；

若偶次项系数和等于奇次项系数和，则

[
\lambda=-1
]

是根。

找到一个根后，用多项式除法继续分解。

# 三、本范围重点、难点与高频易错点【重点】

## 1. 教材明确值得注意的地方

### 易错点A：特征向量必须非零

错误：

[
(\lambda E-A)0=0
]

所以0是特征向量。

错。

正确：

[
\boxed{\xi\ne0}
]

是定义中的硬条件。

---

### 易错点B：解特征向量时，基础解系最后不能取全零系数

教材P141例题在写特征向量时明确保留：

[
k_1,k_2\text{ 不全为0}.
]

---

### 易错点C：实对称矩阵可以利用“必可对角化”反推秩

教材P141的“注1”中，针对单根 (\lambda=10)，直接利用：

[
A\text{ 实对称}
\Longrightarrow
A\text{ 可对角化}
]

因此单根必对应一个线性无关特征向量：

[
\dim N(10E-A)=1,
]

所以

[
r(10E-A)=2.
]

这是一种非常重要的**反向使用定理**。

---

### 易错点D：先观察特征多项式结构，再暴力展开

教材P142—143连续用“行列式性质制造因子”“试根法”处理三阶特征多项式。

考研中常见结构明显时，不推荐直接把三阶行列式完全展开成：

[
\lambda^3+a\lambda^2+b\lambda+c.
]

---

# 2. 最容易混淆的概念

## （1）特征值 vs 特征向量

[
\lambda:\text{数}
]

[
\xi:\text{非零向量}
]

不能写“(\lambda) 的特征值是 (\xi)”这种颠倒表述。

---

## （2）代数重数 vs 几何重数

例如：

[
|\lambda E-A|
=(\lambda-1)^2(\lambda-3).
]

1的代数重数是2。

但如果

[
r(E-A)=2
]

对于三阶矩阵：

[
\dim N(E-A)=1.
]

所以几何重数只有1。

于是：

[
\boxed{A\text{ 不可相似对角化}}.
]

---

## （3）有重特征值 ≠ 不能对角化

错误想法：

> 特征值重复，所以不能对角化。

错。

关键看对应特征向量是否够多。

例如：

[
\operatorname{diag}(1,1,2)
]

显然已经是对角矩阵，1虽然是二重特征值，但有二维特征子空间。

---

## （4）有 (n) 个特征值 ≠ 有 (n) 个不同特征值

(n) 阶矩阵的特征多项式按重数总有 (n) 个根（在复数域计重数），但它们可能重复。

---

## （5）特征值相同 ≠ 相似

相似：

[
\Longrightarrow
]

特征值相同。

反之不成立。

例如：

[
\begin{pmatrix}
1&0\0&1
\end{pmatrix}
,\qquad
\begin{pmatrix}
1&1\0&1
\end{pmatrix}
]

特征值都是 (1,1)，却不相似。

---

## （6）等价、相似、合同不要混

本范围最重要的是相似：

[
B=P^{-1}AP.
]

等价：

[
B=PAQ.
]

合同：

[
B=P^TAP.
]

三者不是同一关系。

---

## （7）同一特征值的向量可相加；不同特征值一般不可相加

这是第1、3、22题共用陷阱。

---

# 3. 常见计算错误

### ① 把 (|A-\lambda E|) 和 (|\lambda E-A|) 混用后忘记符号

(n) 阶有：

[
|A-\lambda E|
=(-1)^n|\lambda E-A|.
]

求根时零点相同，但中间展开式符号可能不同。

建议统一：

[
\boxed{|\lambda E-A|}
]

---

### ② 求特征向量时把矩阵做“列变换”

解

[
(\lambda E-A)x=0
]

是在解线性方程组。

应该优先做：

[
\boxed{\text{初等行变换}}
]

列变换会改变未知量坐标含义。

---

### ③ 重根只看特征方程，不查秩

判断可否对角化时：

[
\boxed{
\text{一旦出现重根}
\to
\text{立刻看 }r(\lambda E-A)
}
]

---

### ④ 构造 (P) 时列顺序和 (\Lambda) 不匹配

极高频失分点。

---

### ⑤ 已经知道特征向量，还重新算特征方程

例如给：

[
A\xi_i=\lambda_i\xi_i,
]

直接用即可。

---

### ⑥ 实对称矩阵还在机械求所有特征向量

若已经知道一个特征空间，另外一个不同特征值对应特征向量常可直接通过**正交条件**求出。

第12、23题特别典型。

---

# 4. 常见思维误区

### 误区1

“求 (A^n) 就直接乘。”

正确：

看到特征值问题中的 (A^n)，第一反应应是：

[
A=P\Lambda P^{-1}
]

于是

[
A^n=P\Lambda^nP^{-1}.
]

---

### 误区2

“给一个矩阵多项式就展开矩阵乘法。”

例如：

[
A+A^2+\frac12A^3=O.
]

若 (A) 对称，应第一反应：

[
\lambda+\lambda^2+\frac12\lambda^3=0.
]

这是把“矩阵方程”降成“数的方程”。

---

### 误区3

“特征值相同，所以相似。”

错。

要证明相似，最直接的方法是找：

[
P^{-1}AP=B.
]

---

### 误区4

“行变换不影响特征值。”

错。

行变换保持的是秩、线性方程组解结构等，不保持一般特征值。

---

### 误区5

“零特征值重数 = (n-r(A))。”

不准确。

[
n-r(A)
]

是**几何重数**。

代数重数只满足：

[
\boxed{
m_{\rm alg}(0)\ge n-r(A).
}
]

第17题就是专门卡这一点。

---

# 【选择题】第1题｜答案：A

## 题目

已知 (A) 为3阶方阵，(1,1,2) 是 (A) 的3个特征值，(\alpha_1,\alpha_2,\alpha_3) 为这3个特征值对应的特征向量，则（　）。

A. (\alpha_1,\alpha_2,\alpha_3) 必为矩阵 (2E-A) 的特征向量
B. (\alpha_1-\alpha_2) 必为矩阵 (2E-A) 的特征向量
C. (\alpha_1+\alpha_3) 必为矩阵 (2E-A) 的特征向量
D. (\alpha_1,\alpha_2) 不是矩阵 (2E-A) 的特征向量，(\alpha_3) 必为其特征向量。

## 教材与官方解析对应

教材P140定义：

[
A\xi=\lambda\xi.
]

官方解析P126直接使用：

[
(2E-A)\alpha_i=(2-\lambda_i)\alpha_i.
]



## 核心解答

若

[
A\alpha_i=\lambda_i\alpha_i,
]

则

[
(2E-A)\alpha_i
==============

# 2\alpha_i-A\alpha_i

(2-\lambda_i)\alpha_i.
]

因此三个原特征向量分别仍是 (2E-A) 的特征向量。

A正确。

B不一定，因为虽然 (\alpha_1,\alpha_2) 都属于特征值1，但题目没有保证

[
\alpha_1-\alpha_2\ne0.
]

若

[
\alpha_1=\alpha_2,
]

则其差为零向量，零向量不是特征向量。

C错误，因为 (\alpha_1,\alpha_3) 对应不同特征值，和一般不是特征向量。

D显然错误。

[
\boxed{A}
]

### 关键理解

这题真正考：

[
\boxed{f(A)\xi=f(\lambda)\xi}
]

以及“零向量不是特征向量”。

★★ 高频易错题。

# 【选择题】第2题｜答案：D，(a=-2)

## 题目

[
A=
\begin{pmatrix}
3&-4&0\
4&-5&0\
a&2&-1
\end{pmatrix}.
]

若 (A) 的三重特征值 (\lambda) 对应两个线性无关的特征向量，求 (a)。

题册选项在C、D处存在排印损坏；官方解析答案为D。

## 核心解答

三阶矩阵，三重特征值对应**两个**线性无关特征向量：

[
\dim N(\lambda E-A)=2.
]

因此：

[
r(A-\lambda E)=1.
]

有

[
A-\lambda E=
\begin{pmatrix}
3-\lambda&-4&0\
4&-5-\lambda&0\
a&2&-1-\lambda
\end{pmatrix}.
]

秩为1意味着三行成比例。

由于第一行第三个元素为0，而第三行第三个元素为

[
-1-\lambda,
]

必须有：

[
-1-\lambda=0
]

故

[
\lambda=-1.
]

此时：

[
A+E=
\begin{pmatrix}
4&-4&0\
4&-4&0\
a&2&0
\end{pmatrix}.
]

要秩为1，第三行与第一行成比例：

[
(a,2,0)
=======

k(4,-4,0).
]

从

[
2=-4k
]

得

[
k=-\frac12.
]

于是

[
a=4\left(-\frac12\right)=-2.
]

[
\boxed{a=-2}
]

官方解析亦得到 (\lambda=-1,a=-2)。

### 矛盾处理

* **题册页面：**C、D选项发生损坏；
* **官方解析：**D；
* **实际推导：**(a=-2)；
* **最终采用：**(\boxed{D,\ a=-2})。

★★ 典型“重数—秩—特征向量个数”题。

P^{-1}A^*P

[
A^*=|A|A^{-1}.

[
A\xi=\lambda\xi

可知：

[
A^{-1}\xi=\frac1\lambda\xi.

于是

[
A^*\xi
======

\frac{|A|}{\lambda}\xi.
]

再设：

[
B=P^{-1}A^*P.
]

则

[
B(P^{-1}\xi)
============

# P^{-1}A^*\xi

\frac{|A|}{\lambda}P^{-1}\xi.
]

所以：

[
\boxed{
\text{特征值}=\frac{|A|}{\lambda},
\quad
\text{特征向量}=P^{-1}\xi
}
]

即：

[
\boxed{A}

# 【选择题】第6题｜答案：A

先将 (A) 第2列加到第3列得 (B)，再将 (B) 第3行的 (-1) 倍加到第2行，得到：

[
C=
\begin{pmatrix}
1&1&0\
0&2&0\
0&2&a
\end{pmatrix}.
]

求 (A) 的特征值。

## 第一突破口

一般行、列变换**不保持特征值**。

但本题两个变换是刻意配成相似变换。

令

[
P=
\begin{pmatrix}
1&0&0\
0&1&1\
0&0&1
\end{pmatrix}.
]

第2列加到第3列：

[
B=AP.
]

而

[
P^{-1}
======

\begin{pmatrix}
1&0&0\
0&1&-1\
0&0&1
\end{pmatrix},
]

左乘 (P^{-1}) 正好把第3行的 (-1) 倍加到第2行：

[
C=P^{-1}AP.
]

所以：

[
A\sim C.
]

(C) 是三角型：

[
\lambda=1,2,a.
]

故：

[
\boxed{A}
]

### 最容易错

不能只说：

> “做了初等变换，所以特征值不变。”

必须说明：

[
\boxed{C=P^{-1}AP}
]

才成立。

\boxed{\lambda_3=1}.
]

---

## 第三步：利用对称矩阵正交性求 (\lambda=1) 的特征向量

设：

[
\xi=(x,y,z)^T.
]

应同时与两个0特征向量正交：

[
-2x+y=0,
]

[
-3x+z=0.
]

所以：

[
y=2x,\qquad z=3x.
]

可取：

[
(1,2,3)^T.
]

单位化：

[
\eta
====

\frac1{\sqrt{14}}
\begin{pmatrix}
1\2\3
\end{pmatrix}.
]

---

## 第四步：构造A

由于特征值只有：

[
0,0,1,
]

所以A实际上就是向 (\eta) 方向的正交投影矩阵：

[
A=\eta\eta^T.
]

因此：

[
A
=

\frac1{14}
\begin{pmatrix}
1&2&3\
2&4&6\
3&6&9
\end{pmatrix}.
]

即：

[
\boxed{
A=
\begin{pmatrix}
\frac1{14}&\frac17&\frac3{14}[2pt]
\frac17&\frac27&\frac37[2pt]
\frac3{14}&\frac37&\frac9{14}
\end{pmatrix}.
}
]

由于：

[
A^2=A,
]

所以对任意正整数 (n)：

[
\boxed{
A^n=A.
}
]

即：

[
\boxed{
A^n=
\begin{pmatrix}
\frac1{14}&\frac17&\frac3{14}[2pt]
\frac17&\frac27&\frac37[2pt]
\frac3{14}&\frac37&\frac9{14}
\end{pmatrix},
\qquad n\ge1.
}
]

官方解析也是先用核空间得到两个0特征值，再利用对称性找第三个正交特征向量。

[
\boxed{A\xi=\lambda\xi,\quad \xi\ne0}

[
\boxed{|\lambda E-A|=0}

[
\boxed{(\lambda E-A)x=0}

}
]

[
\boxed{
A\text{可对角化}

A\text{有 }n\text{个线性无关特征向量}

m_g(\lambda)

n-r(\lambda E-A)

m_g(\lambda)\le m_a(\lambda)
}
]

\boxed{
P=(\xi_1,\ldots,\xi_n)
\Rightarrow

}

[
\boxed{
A^n=P\Lambda^nP^{-1}
}
]

[
\boxed{
A^*=|A|A^{-1}
}
]

[
\boxed{
\lambda(A^*)=\frac{|A|}{\lambda(A)}
\quad(A\text{可逆})
}
]

## 2. 教材特别值得记忆的二级结论

### ① 求特征值是“起步，也是关键”

教材P142明确强调这一点。

### ② 特征向量必须非零

最基本、也最容易被选择题卡。

### ③ 实对称矩阵可以利用“必可对角化”反推特征空间维数

教材P141例题已经实际这么做。

## 3. 高频解题套路

> **看到 (A\xi=\lambda\xi)**
> → 不算特征方程
> → 直接使用特征关系。

> ]

> **看到 (A^n)**

# 4. 本范围最重要的易错点排序

### No.1

错误：

> 二重特征值一定有两个线性无关特征向量。

正确：

[
\boxed{
m_g\le m_a.
}
]

---

### No.2

错误：

> 有重特征值就不能对角化。

正确：

看几何重数是否等于代数重数。

---

### No.3

错误：

> 有相同特征值就相似。

正确：

[
A\sim B
\Rightarrow
\lambda(A)=\lambda(B),
]

反之不成立。

---

### No.4

错误：

> 初等行变换保持特征值。

正确：

一般不保持；只有形成

[
P^{-1}AP
]

才保持。

---

### No.5

错误：

> (n-r(A)) 是0的代数重数。

正确：

它是几何重数。

---

### No.6

错误：

> 特征向量可以取0。

正确：

定义要求非零。

---

### No.7

错误：

> 不同特征值对应的特征向量也可以任意相加。

正确：

一般不能。

---

### No.8

错误：

> 构造P只要把特征向量放进去即可，不管顺序。

正确：

P列顺序必须与 (\Lambda) 对角线顺序一致。
