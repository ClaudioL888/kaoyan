## 4. 未来统一题型接口／方法池

以下各项只是未来显式题目进入时使用的接口。当前关联题号全部为空。

### 4.1 哲学基本问题与派别判定

- 理论/史实对象：思维与存在；无独立史实对象。
- 限定词：本原、第一性、同一性、能否认识。
- 概念边界：唯物/唯心；可知/不可知；二元论边界。
- 材料映射：世界本原、认识可能性、哲学派别表述。
- 干扰机制：用日常价值态度代替哲学标准；把可知论直接等同唯物主义。
- 分析题组织：先分哲学基本问题两个方面，再判断材料回答哪一方面。
- 版本性质：`STATIC`；教师提纲。

### 4.2 物质—运动—时空规范搭配

- 理论/史实对象：物质范畴及其存在方式。
- 限定词：唯一特性、根本属性、存在方式、基本存在形式、绝对、相对。
- 概念边界：客观实在性/运动/时空；物质/具体物质形态；运动/静止。
- 材料映射：借助仪器感知、位置暂时不变、具体时空条件。
- 干扰机制：地位词互换；把静止说成无运动；把自然科学结构模型等同哲学物质。
- 分析题组织：定义物质后依次说明运动、时空及其条件。
- 版本性质：`STATIC`。

### 4.3 意识能动性与人工智能边界

- 理论/史实对象：意识起源、本质、作用及人工智能。
- 限定词：决定、依赖、反作用、前提、根本途径、物质条件。
- 概念边界：物质决定意识/意识反作用；主观能动性/主观任意性；人类意识/工具模拟。
- 材料映射：劳动、语言、实践、算法生成和机器模拟。
- 干扰机制：把人脑当意识源泉；把 AI 功能升级为社会或价值主体；把能动性写成创造规律。
- 分析题组织：物质决定意识 → 意识能动作用 → 发挥条件 → 材料中的实践或 AI 边界。
- 版本性质：`STATIC`；AI 例示不是年度时政结论。

### 4.4 联系、规律与新旧事物

- 理论/史实对象：联系特征、发展实质、规律客观性。
- 限定词：普遍、任意、条件、创造/改变规律、新出现、发展。
- 概念边界：联系普遍性/具体联系条件性；变化/发展；新事物/新出现事物。
- 材料映射：人为建立联系、环境变化、新形式和利用规律。
- 干扰机制：从普遍联系推出任意联系；以出现时间判断新事物；把改变条件说成改变规律。
- 分析题组织：联系条件 → 发展方向 → 规律客观性 → 人在实践中改变条件。
- 版本性质：`STATIC`。

### 4.5 矛盾基本属性与发展动力

- 理论/史实对象：同一性、斗争性及其作用。
- 限定词：相互依存、转化、排斥、有条件/无条件、内因/外因。
- 概念边界：同一性/斗争性；内因/外因；辩证矛盾/逻辑矛盾。
- 材料映射：合作竞争、力量变化、内部矛盾和外部条件。
- 干扰机制：把同一性说成无差别；把斗争局限为公开冲突；让外因脱离内因起决定作用。
- 分析题组织：矛盾双方 → 两种属性 → 各自作用 → 条件与材料对应 → 发展结论。
- 版本性质：`STATIC`。

### 4.6 矛盾层级与具体问题具体分析

- 理论/史实对象：普遍性/特殊性、主要/次要矛盾、主要/次要方面。
- 限定词：共性、个性、决定进程、决定性质、重点。
- 概念边界：普遍性/特殊性不是整体/部分；主要矛盾/矛盾主要方面。
- 材料映射：不同对象或阶段、复杂矛盾体系、一对矛盾双方。
- 干扰机制：把共性说成包含全部个性；把主要矛盾和主要方面互换；把重点论变成一点论。
- 分析题组织：确定比较层级 → 指出主要对象 → 兼顾其他方面 → 两点论与重点论统一。
- 版本性质：`STATIC`。

### 4.7 质量互变与适度原则

- 理论/史实对象：质、量、度、量变和质变。
- 限定词：积累、范围、界限、飞跃、必要准备、必然结果。
- 概念边界：质/量；量变/质变；关节点/度的范围。
- 材料映射：数量积累、超过临界点、条件成熟。
- 干扰机制：激变论、庸俗进化论；把度当单个点；认为任何微变立即质变。
- 分析题组织：确定事物的质 → 识别量的积累 → 判断是否越度 → 说明新质开启新量变。
- 版本性质：`STATIC`。

### 4.8 辩证否定与发展道路

- 理论/史实对象：自我否定、扬弃和否定之否定。
- 限定词：自身、克服、保留、两次否定、螺旋上升。
- 概念边界：自我否定/外部消灭；扬弃/全盘抛弃；前进性/曲折性。
- 材料映射：新旧因素继承、阶段性回复、发展曲折。
- 干扰机制：把外力消灭当辩证否定；简单循环；绝对肯定或否定。
- 分析题组织：内部矛盾导致否定 → 克服与保留 → 新阶段 → 前进性和曲折性统一。
- 版本性质：`STATIC`。

### 4.9 五对范畴的关系识别

- 理论/史实对象：内容形式、本质现象、因果、必偶、现可。
- 限定词：决定/反作用、表面/根本、引起/被引起、趋势/机遇、根据/条件。
- 概念边界：真象/假象/错觉；原因/时间先后；必然/偶然；现实/可能。
- 材料映射：表象判断、因果链、偶发事件、条件成熟、风险与机遇。
- 干扰机制：以时间先后代替因果；把假象当主观错觉；把可能等同愿望；忽视偶然作用。
- 分析题组织：确定范畴对 → 分别定义 → 说明依存和转化条件 → 回扣材料。
- 版本性质：`STATIC`。

### 4.10 辩证思维与方法选择

- 理论/史实对象：矛盾分析、历史、系统、战略和底线等思维。
- 限定词：根本方法、具体分析、整体、长期、底线。
- 概念边界：方法名称/具体论证；系统/要素简单相加。
- 材料映射：复杂系统、历史过程、全局风险和多目标决策。
- 干扰机制：只罗列方法名；脱离材料；把底线思维理解为消极保守。
- 分析题组织：原理定位 → 方法含义 → 材料事实 → 结构或条件分析 → 回应设问。
- 版本性质：`STATIC`；方法压缩语不等于官方标准答案。

## 5. 隐式例示的内部关联边界

| 隐式证据归纳 | 未来接口 | 识别边界 |
|---|---|---|
| 磁场等借助仪器感知 | 物质—运动—时空 | 客观实在不要求裸眼直接可见 |
| “不能两次踏进同一条河流”等说明 | 运动与静止 | 用于排查否定相对静止的相对主义 |
| AI 模拟语言、生成内容 | 意识与 AI | 只归纳工具能力与意识主体边界 |
| 人在实践中建立新的联系 | 联系与规律 | 建立具体联系不等于创造规律 |
| 新出现者未必是新事物 | 新旧事物 | 按历史前进方向和生命力判断 |
| 水果与苹果、汽车与零部件的对比 | 普遍性与特殊性 | 一般/个别不同于整体/部分 |
| 外力消灭对象与事物自我否定 | 辩证否定 | 外部消灭不能替代内部矛盾导致的自我发展 |
| 真象、假象与错觉 | 本质与现象 | 真象、假象是客观现象，错觉是主观认识 |
| “凡事预则立，不预则废”等说明 | 原因与结果 | 时间先后不足以证明因果 |
| 现实可能与抽象可能 | 现实与可能 | 是否具有现实根据和条件是最低识别线 |

这些例示只证明接口有提纲依据，不证明考试已经以具体题号考查。
