## 2. 教材核心知识体系

### 2.1 函数、定义域和值域

教材把函数核心表述为：定义域中每一个自变量按确定法则对应唯一函数值。复习时先判定义域，再处理表达式；分段函数必须检查分界点归属。复合函数要检查内层函数值是否落入外层定义域。

### 2.2 反函数与复合

严格单调是有反函数的充分条件；反函数图像关于`y=x`对称。必须区分`f^{-1}(f(x))=x`和`f(f^{-1}(x))=x`的适用域。有反函数不等于函数必须严格单调。

### 2.3 有界、单调、奇偶、周期

利用`(x_1-x_2)(f(x_1)-f(x_2))`判断严格单调；判断奇偶性前先确认定义域关于原点对称；周期性要验证`f(x+T)=f(x)`，不能只因某个因子周期就断定乘积周期。偶函数与奇函数的乘积为奇函数。

### 2.4 极限、无穷小和等价替换

核心公式：

`sin x ~ x`，`1-cos x ~ x^2/2`，`tan x ~ x`，`ln(1+x)~x`，`e^x-1~x`，`arctan x~x`，`arcsin x~x`。

等价无穷小可直接用于乘除；加减结构必须先展开到抵消后的第一个非零项。`f=o(g)`表示`f/g→0`，不等价于恒等式，也不能把`f~g`写成`f=g`。

### 2.5 连续与间断点

连续要求函数值存在、极限存在且等于函数值。可去间断点的极限有限但函数值缺失或不相等；跳跃间断点左右极限存在但不相等；无穷间断点趋于无穷；振荡间断点极限不存在且非无穷型。分段函数优先检查分界点。

| 底数趋1、指数趋无穷 | 取对数，匹配底数偏离1的阶 | 不能只看底数极限 |
| `0^0`型 | 取对数，分离`ln`底数 | 不能直接判为1 |
| `1/x∫_0^x` | 积分中值定理 | 注意左右方向与连续性 |
| 变上限积分 | 先估上限阶，再估被积函数阶 | 不能只代`t=0` |
| 等价无穷小加减 | 展开到抵消后的首个非零项 | 不能直接逐项替换 |
| 参数等价 | 先消低阶项，再匹配系数 | 忽略一次项会得错参数 |
| 分母和分子同时含参数 | 先令低阶项为零 | 不能直接代入发散形式 |
| 分段/定义域洞 | 逐点求左右极限 | 极限有限不等于连续 |
| 含`|x|` | 先写分段表达式 | 绝对值会改变左右符号 |
| 含`n→∞`和`x` | 按`|x|<1,=1,>1`分类 | 不能只在固定x范围外推 |
| `f~g` | 可推出差为`o(f)`、`o(g)` | 不等于恒等式 |
