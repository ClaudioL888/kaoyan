# 线性表：题型方法

> 记录时间：2026-08-20 19:37:53 +08:00

## 已确认增量

### 1. 顺序表稳定压缩、删除和去重（全新）

识别信号：一次扫描中删除满足条件的多个元素、要求保序或原地。

做法：读指针扫描原表，写指针只写入应保留元素；循环不变式是写指针前缀恰好为已扫描元素中应保留者的原相对次序。最后更新长度。

复杂度：时间 \(O(n)\)，额外空间 \(O(1)\)。边界：空表、全部删除、无元素删除、长度字段更新。

### 2. 顺序表分段交换与多指针（全新）

- 块交换/循环移位：三次逆置，先逆置两段，再逆置整体；要先写清段端点。
- 已排序序列、最小距离、合并：让每个指针只向前推进，推进规则由当前比较关系确定。
- 众数：候选抵消只产生候选者，必须再扫描一次验证频率。

### 3. 单链表修改：`pre,p,r` 不变式（全新）

识别信号：原地删除、逆置、重排、合并或分割链表。

标准过程：`r = p->next` 保存后继；再修改 `p->next`；最后移动 `pre/p`。每轮都要说明已处理链、当前结点、未处理链的边界。

复杂度：一次线性扫描时 \(O(n)\)、额外空间 \(O(1)\)。风险：先改链接后保存后继会断链。

### 4. 双链表/循环链表的链接闭合（全新）

双链表插删逐项校验前驱和后继的 `next/prior`；循环链表先固定是否有头结点，再写空表、单结点、尾结点条件。不要把尾指针指向首元还是头结点混作同一表示。

### 5. 快慢指针与公共结点（全新）

- 环检测、中点、倒数第 \(k\) 个：使用速度差或固定间距；进入循环前检查空指针。
- 公共物理结点：先对齐长度，或双指针换头；比较地址而不是数据域。
- 有序链表题先判目标：是输出公共值、建立新链、原地求交，还是找同一物理尾部。

### 6. 链表重排三段式（相邻）

找中点 → 逆置后半段 → 交替穿插。每次穿插前暂存两个后继，避免覆盖未连接部分；适用于“前后半段交替”的线性表重排题。

### 父池 A：逻辑结构与实现选型（补充/相邻）

- **T01 线性表 ADT 与逻辑次序：**有限序列、同类型元素、唯一前驱/后继；长度为 1 时首尾为同一元素。关联：2.1选01—04。
- **T02 存储结构选型与操作代价：**先看访问、定位、插删和前后驱需求；定位成本与已定位后的操作成本分开。关联：2.2选01、05、06、08；2.3选01、02、04、05、12、14。
- **T03 顺序表连续存储、随机访问与容量：**按位序访问/修改为 O(1)，按值查找不因此成为 O(1)；扩容要求连续空间。关联：2.2选02、03、04、11、12、13。
- **T04 顺序表插删移动计数：**插入腾位、删除补位，移动方向避免覆盖；一般 O(n)，末端且容量足够时可 O(1)。关联：2.2选07、09、10。
- **T08 单链表基本表示、头结点与空表：**物理地址可不连续；有无头结点的空表条件不同。关联：2.3选03、09、11。
- **T13 静态链表游标与容量：**数组下标模拟链接而非逻辑位序；容量预先确定，插删不移动但定位仍需顺链。关联：2.3选30、31。

### 父池 B：顺序表扫描、多指针与值域模型（补充后相邻拆分）

- **T05 单扫描原地筛选/替换：**读写前缀保持应保留元素；若不要求稳定可用尾元素回填。关联：2.2应01、03、04、05。
- **T06 有序顺序表单调指针与区间缩减：**二/三路推进或中位数区间排除，每步缩小未决范围。关联：2.2应06、08、09、11、14。
- **T07 全局统计与值域辅助结构：**候选抵消后必须验证；值域标记只覆盖可能答案；负数乘积同时维护后缀最大/最小。关联：2.2应12、13、15。

### 父池 C：单链表局部改链、构造与匹配（补充/相邻）

- **T09 局部改链与可达性不变量：**先保存未处理后继，再改链并推进；已知前驱时局部操作 O(1)，定位另计。关联：2.3选06、10、33、36；2.3应01、02、04。
- **T10 构造、拼接与连续子序列匹配：**头插会反序；无尾指针拼接需找尾；连续子序列要求相邻匹配并处理失配重启。关联：2.3选07、08、13；2.3应10。

### 父池 D：双向/循环链接的闭合与端点（补充后相邻拆分）

- **T11 双链表双向闭合与对称：**保持 `x->next->prior==x` 与 `x->prior->next==x`；赋值顺序不得覆盖旧邻居。关联：2.3选15、16、17、18、20、28、32、35；2.3应11。
- **T12 循环链表端点表示与 O(1) 操作：**先固定有无头结点及头/尾指针语义；仅头指针时找尾可能 O(n)。关联：2.3选21—27、29、34；2.3应12。
- **T17 按访问频度自组织双链表：**命中后频度加一并稳定前移；频度递减、同频最近访问者在前。关联：2.3应13。

### 父池 E：结构性双指针与有序集合（补充后相邻拆分）

- **T14 快慢指针、长度对齐与结构性相遇：**用速度差、固定间距或长度差求环、倒数位置和公共物理结点；比较地址而非数据值。关联：2.3应05、15、17、18。
- **T15 有序链表归并、去重与集合运算：**二路指针单调推进；相等时依输出语义决定新建、保留或释放。关联：2.3选19；2.3应07、08、09。
- **T18 值域辅助去重并释放结点：**标记此前保留结点的绝对值，首次保留、后续删除；检查 0、n 和释放后的推进。关联：2.3应19。

### 父池 F：跨顺序/链式的分段变换与重排（补充）

- **T16 分段逆置、旋转、拆分与重排：**顺序表用三次逆置；链表用中点—逆置—拼接、奇偶拆链或成环—断环；全过程保持不重不漏。关联：2.2应02、07、10；2.3应03、06、14、16、20。
