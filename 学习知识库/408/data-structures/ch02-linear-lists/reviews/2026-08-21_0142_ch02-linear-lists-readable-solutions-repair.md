### 2.1选01｜答案 C｜T01

#### 题目（视觉核对题面）

> 线性表是具有 𝑛个（   ）的有限序列。
> A.数据表           B.字符                   C.数据元素             D.数据项

- 题面来源：横版选择题本P14；教材印刷页14 / PDF阅读页26视觉核对
- 正式解析定位：教材印刷页14—15 / PDF阅读页26—27。
- 要素核对：主题型 T01；状态/不变量：有限线性次序及首尾关系；复杂度：定义题不适用；边界：空表与单元素表。

题干：线性表是具有 n 个（ ）的有限序列。A 数据表；B 字符；C 数据元素；D 数据项。

- A 错：数据表不是线性表定义中的基本对象。
- B 错：字符只能是某些线性表的数据元素类型，不具普遍性。
- C 对：教材定义为“相同数据类型的 n 个数据元素的有限序列”。
- D 错：数据项是数据元素的组成成分，粒度低一级。
- 教材依据：印刷页13—14的定义与解析；独立核查一致。
- 第一反应：看到定义空格，区分“数据元素”和“数据项”。边界：n 可为0。

### 2.2选01｜答案 A｜T02

#### 题目（视觉核对题面）

> 下列叙述中，（ ）是顺序存储结构的优点。
> A.存储密度大                       B.插入运算方便
> C.删除运算方便                      D.方便地运用于各种逻辑结构的存储表示

- 题面来源：横版选择题本P18；教材印刷页18 / PDF阅读页30视觉核对
- 正式解析定位：教材印刷页21—22 / PDF阅读页33—34。

### 2.2选02｜答案 C｜T03

#### 题目（视觉核对题面）

> 下列关于顺序表的叙述中，正确的是（      ）。
> A.顺序表可以利用一维数组表示，因此顺序表与一维数组在逻辑结构上是相同的
> B.在顺序表中，逻辑上相邻的元素物理位置上不一定相邻
> C.顺序表和一维数组一样，都可以进行随机存取
> D.在顺序表中，每个元素的类型不必相同

- 题面来源：横版选择题本P18；教材印刷页18 / PDF阅读页30视觉核对
- 正式解析定位：教材印刷页21—22 / PDF阅读页33—34。

题干：关于顺序表的正确叙述。A 与一维数组逻辑结构相同；B 逻辑相邻物理不一定相邻；C 与一维数组一样可随机存取；D 元素类型不必相同。

- A 错：数组是存储载体；顺序表是线性表的一种存储实现，概念层次不同。

### 2.2应01｜删除唯一最小值，以末元素回填｜T05

#### 题目（视觉核对题面）

> 从顺序表中删除具有最小值的元素（假设唯一）并由函数返回被删元素的值。空出的位
> 置由最后一个元素填补，若顺序表为空，则显示出错信息并退出运行。

- 题面来源：横版应用题本P20；教材印刷页20 / PDF阅读页32视觉核对
- 正式解析定位：教材印刷页22—23 / PDF阅读页34—35。
- 要素核对：主题型 T05；状态/不变量：写入前缀恰为已扫描部分应保留元素；复杂度：O(n)/O(1)；边界：空表、全删、长度更新。

- 输入/输出：非空顺序表 L；返回唯一最小值并删除该项。
- 方法：扫一遍维护 `minValue,minPos`；扫描结束后令 `L[minPos]=L[length-1]`，长度减1。
- 不变量：扫描到 i 后，`minValue` 是前缀 `[0..i]` 的最小值，`minPos` 是其位置。
- 伪代码：`if length==0 return false; minPos=0; for i=1..length-1 if L[i]<L[minPos] minPos=i; value=L[minPos]; L[minPos]=L[length-1]; length--; return true`。
- 复杂度：O(n) 时间、O(1) 空间。
- 边界：空表失败；单元素表回填自身后长度变0；该题明确不要求保序，因此末项回填合法。
- 教材依据：印刷页22—23正式解答；独立核查一致。

### 2.2应06｜合并两个有序顺序表｜T06

#### 题目（视觉核对题面）

> 将两个有序顺序表合并为一个新的有序顺序表，并由函数返回结果顺序表。

- 题面来源：横版应用题本 P20；教材印刷页20 / PDF阅读页32视觉核对（图像页人工转录）
- 正式解析定位：教材印刷页24—25 / PDF阅读页36—37。
- 要素核对：主题型 T06；状态/不变量：各指针之前的有序前缀已完整处理；复杂度：线性归并或对数缩区间；边界：相等、耗尽和容量。

- 方法：i、j分别指向A/B当前项，较小者写入C[k]；一表耗尽后复制另一表剩余项。
- 不变量：每轮前 `C[0..k-1]` 是 A、B 已消费前缀的完整有序归并。
- 伪代码：`while i<aLen && j<bLen: C[k++]=(A[i]<=B[j]?A[i++]:B[j++]); copy remainder; C.length=k`。
- 复杂度：O(m+n) 时间；输出表空间 O(m+n)，除输出外 O(1)。

### 2.3应03｜就地逆置带头结点单链表｜T16

#### 题目（视觉核对题面）

> 试编写算法将带头结点的单链表就地逆置，所谓“就地”是指辅助空间复杂度为𝑂(1)。

- 题面来源：横版应用题本P43；教材印刷页43 / PDF阅读页55视觉核对
- 正式解析定位：教材印刷页51—52 / PDF阅读页63—64。

- O(n)/O(1)；空表、单结点均自然成立。

### 2.3应11｜判断循环双链表是否对称｜T11（1问）

#### 题目（视觉核对题面）

> 设计一个算法用于判断带头结点的循环双链表是否对称。

- 题面来源：横版应用题本 P44；教材印刷页44 / PDF阅读页56视觉核对（图像页人工转录）
- 正式解析定位：教材印刷页55—56 / PDF阅读页67—68。
- 要素核对：主题型 T11；状态/不变量：每条next关系均由对应prior闭合；复杂度：已定位改链O(1)；边界：首尾、空表和赋值次序。

- `p=L->next,q=L->prior`从首尾向中间走；当`p==q`（奇数长度）或`p->next==q`（偶数长度）时比较完成。
- 每轮先比较data，异则返回0；同则`p=p->next,q=q->prior`。
- 不变量：p左侧与q右侧已成镜像相等。O(n)时间、O(1)空间。
- 边界：空表/单结点对称；循环条件不能误写成`q->next!=p`，否则偶数长度越过后可能继续绕圈。

### 2.3应13｜Locate后按freq递减重排｜T17（1问）

#### 题目（视觉核对题面）

> 有一个访问频度域 freq，其值均初始化为零。每当在链表中进行一次 Locate(L,x)运算时，令
> 值为 x的结点中 freq域的值增 1，并使此链表中的结点保持按访问频度递减的顺序排列，且最近
> 访问的结点排在频度相同的结点之前，以便使频繁访问的结点总是靠近表头。试编写符合上述要
> 求的 Locate(L,x)函数，返回找到结点的地址，类型为指针型。

- 题面来源：横版应用题本P44；教材印刷页44 / PDF阅读页56视觉核对
- 正式解析定位：教材印刷页56—57 / PDF阅读页68—69。

- 不变量：除p外链表始终按freq递减；插入后p前方频率严格更大，后方不大于p。
- O(n)/O(1)。边界：未找到x应返回NULL而非退出进程；首/尾摘插需维护双向闭合。

> (1)给出算法的基本设计思想。
> (2)根据设计思想，采用 C或C++语言描述算法，关键之处给出注释。

> 的最后一个结点的指针域是空的）。试编写算法判断单链表是否存在环。

> (2)根据设计思想，采用 C或C++语言描述算法，关键之处给出注释。

> 链表只给出了头指针 list。在不改变链表的前提下，请设计一个尽可能高效的算法，查找链表中

> 否则，只返回 0。要求：
> (1)描述算法的基本设计思想。
> (2)描述算法的详细实现步骤。
> ，关
> (3)根据设计思想和实现步骤，采用程序设计语言描述算法（使用C、C++或Java语言实现）
> 键之处请给出简要注释。

1. 思想：p先走k步（或形成k个结点间距），再令p、q同步；p到尾时q即倒数第k个。
2. 详细步骤：p、q均从首元开始，计数到k前只移动p；若p提前NULL则k超长失败；形成间距后同步移动，直到p到NULL，输出q->data并返回1。
3. 伪代码：`if(k<=0)return 0; p=q=head->next; for(i=0;i<k;i++){if(!p)return 0;p=p->next;} while(p){p=p->next;q=q->next;} output(q->data);return 1;`。
- O(n)/O(1)。边界：k=1返回尾；k=长度返回首；教材计数写法与此等价，但必须统一“先走k步”还是“间隔k-1条边”的口径。

### 2.3应18｜找两个单词链表共同后缀起点｜T14（3问）

#### 题目（视觉核对题面）

> 【2012统考真题】假定采用带头结点的单链表保存单词，当两个单词有相同的后缀时，
> 可共享相同的后缀存储空间，例如，loading和 being的存储映像如下图所示。
> 图示等价链接：`l→o→a→d→i→n→g` 与 `b→e→i→n→g` 从字符 i 所在结点起共享同一段结点，p 指向该 i 结点。
> 设 str1和 str2分别指向两个单词所在单链表的头结点，链表结点结构为 data       next ，请设计
> 一个时间上尽可能高效的算法，找出由 str1和 str2所指向两个链表共同后缀的起始位置（如图
> 中字符 i所在结点的位置p）。要求：
> (1)给出算法的基本设计思想。
> (2)根据设计思想，采用C或C++或Java语言描述算法，关键之处给出注释。
> (3)说明你所设计算法的时间复杂度。

- 题面来源：横版应用题本P45；教材印刷页45 / PDF阅读页57视觉核对
- 正式解析定位：教材印刷页59—60 / PDF阅读页71—72。
- 要素核对：主题型 T14；状态/不变量：速度差、固定间距或到尾剩余距离保持；复杂度：O(n)/O(1)；边界：NULL检查、地址比较和k合法性。

1. 思想：分别求两链长度m、n；长链先走`|m-n|`步，使两指针到尾剩余距离相等；同步前进，首次地址相同处就是共同后缀起点。
2. 伪代码：`p=str1->next;q=str2->next; advance longer by abs(m-n); while(p!=q){p=p->next;q=q->next;} return p;`。p可能为NULL，表示无共同后缀。
3. 复杂度：O(m+n)时间、O(1)空间。
- 边界：必须比结点地址，不比字符值；“相同后缀共享存储”意味着相交后不再分叉。

### 2.3应19｜按data绝对值去重｜T18（4问）

#### 题目（视觉核对题面）

> 【2015统考真题】用单链表保存m个整数，结点的结构为[data][link]，且|𝑑𝑎𝑡𝑎| ⩽ 𝑛
> （n为正整数）。现要求设计一个时间上尽可能高效的算法，对于链表中 data的绝对值相等的结点，
> 仅保留第一次出现的结点而删除其余绝对值相等的结点。例如，若给定的单链表head如下：
> 图示输入链：`head→21→-15→-15→-7→15→NULL`；处理后为 `head→21→-15→-7→NULL`。
> 要求：
> (1)给出算法的基本设计思想。
> (2)使用 C或C++语言，给出单链表结点的数据类型定义。
> (3)根据设计思想，采用 C或C++语言描述算法，关键之处给出注释。
> (4)说明你所设计算法的时间复杂度和空间复杂度。

- 题面来源：横版应用题本P45；教材印刷页45 / PDF阅读页57视觉核对
- 正式解析定位：教材印刷页60—61 / PDF阅读页72—73。
- 要素核对：主题型 T18；状态/不变量：seen记录已保留绝对值，重复即摘链；复杂度：O(m)时间/O(n)空间；边界：0、负数、释放和数组下标。

1. 思想：因`|data|≤n`，建`seen[0..n]`。以pre/p扫描；若`seen[abs(p->data)]==0`则标记并保留，否则摘链释放。
2. 类型：`typedef struct node { int data; struct node *link; } NODE, *PNODE;`。
3. 伪代码：`seen=calloc(n+1,sizeof(bool)); pre=head;p=head->link; while(p){v=abs(p->data); if(!seen[v]){seen[v]=true;pre=p;p=p->link;}else{q=p;p=p->link;pre->link=p;free(q);}} free(seen);`。
4. 复杂度：m个结点仅扫描一次，O(m)时间、O(n)辅助空间。
- 边界：保留第一次出现；0的绝对值为0；`abs(INT_MIN)`有工程溢出风险，但题设值域受n限制；分配失败需处理。

### 2.3应20｜重排为a1,an,a2,an-1,…｜T16（3问）

#### 题目（视觉核对题面）

> 【2019统考真题】设线性表 L=(a1,a2,a3,…,an-2,an-1,an) 采用带头结点的单链表保存，链表结点定义如下：
> typedef struct node {
>     int data;
>     struct node *next;
> } NODE;
> 请设计一个空间复杂度为 O(1) 且时间上尽可能高效的算法，重新排列 L 中的各结点，得到线性表 L'=(a1,an,a2,an-1,a3,an-2,…)。要求：
> (1) 给出算法的基本设计思想。
> (2) 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
> (3) 说明你所设计算法的时间复杂度。

- 题面来源：横版应用题本 P45；教材印刷页45 / PDF阅读页57视觉核对（图像页人工转录）
- 正式解析定位：教材印刷页61—62 / PDF阅读页73—74。
- 要素核对：主题型 T16；状态/不变量：分段逆置/摘链前保存后继，元素不丢不重；复杂度：O(n)/O(1)；边界：中点、空段及奇偶长度。

1. 思想：快慢指针找前半段尾p；断开并逆置后半段；以s遍历前半、q遍历逆置后半，交替把q插到s之后。
2. 关键过程：`q=p->next;p->next=NULL;q=reverse(q); s=h->next; while(q){r=q->next;q->next=s->next;s->next=q;s=q->next;q=r;}`。每轮先保存r，避免丢失后半剩余链。
3. 复杂度：找中点、逆置、穿插各O(n)，总O(n)时间、O(1)空间。
- 边界：奇偶长度均可按中点口径处理；题目给带头结点；重排后尾next必须为NULL。
