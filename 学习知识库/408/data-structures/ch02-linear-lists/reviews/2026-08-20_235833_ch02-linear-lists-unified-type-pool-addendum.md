## 3. 全章统一题型池

题型 ID 是本次审计用稳定代号。主题型按“对象—算法模型—状态/不变量—操作—复杂度/实现边界”确定，不按题面关键词机械拆分。

### T01 线性表 ADT 与逻辑次序

- 对象：有限序列、数据元素、前驱/后继、ADT。
- 算法模型：定义判定与逻辑结构辨析。
- 状态/不变量：除首元素外每个元素有唯一直接前驱；除尾元素外有唯一直接后继；长度为 1 时首尾为同一元素。
- 操作：识别合法线性表、判断长度与逻辑关系。
- 复杂度/边界结论：非算法计数题；重点是有限性、同类型元素、序列而非集合。2.1 选 04 保留答案冲突。
- 全部关联：2.1选01—04。

### T02 存储结构选型与操作代价比较

- 对象：顺序表、单/双/循环链表及操作需求。
- 算法模型：按访问、定位、插删、前驱/后继需求选实现。
- 状态/不变量：逻辑结构不因存储方式改变；定位成本与已定位后的操作成本分开。
- 操作：随机访问、顺序输出、尾删、批量删除、交换、端点插删。
- 复杂度/边界结论：不存在无条件“顺序优于链式”或相反；必须写清是否已知位置/前驱/尾指针。
- 全部关联：2.2选01、05、06、08；2.3选01、02、04、05、12、14。

### T03 顺序表连续存储、随机访问与容量

- 对象：连续数组、位序、下标、长度、容量、元素宽度。
- 算法模型：地址偏移与直接定位。
- 状态/不变量：逻辑相邻对应物理相邻；有效区间与容量边界分离。
- 操作：按位序访问/修改、空间占用判断、扩容申请。
- 复杂度/边界结论：按位序访问/修改为 O(1)；按值查找不是 O(1)；扩容要求连续空间。
- 全部关联：2.2选02、03、04、11、12、13。

### T04 顺序表插删移动计数

- 对象：长度为 n 的顺序表及指定位置 i。
- 算法模型：维护连续性的区间搬移。
- 状态/不变量：插入前为插入点腾位，删除后填补空位；移动方向避免覆盖。
- 操作：第 i 位插入/删除、末端插入。
- 复杂度/边界结论：一般 O(n)，末端且容量足够时插入可为 O(1)；删除第 i 个需移动 n-i 个。
- 全部关联：2.2选07、09、10。

### T05 顺序表单扫描原地筛选/替换

- 对象：无序或有序顺序表。
- 算法模型：扫描、选择目标、读写双指针或尾元素回填。
- 状态/不变量：已写前缀恰为应保留元素；若题目不要求稳定，可用尾元素填空。
- 操作：删最小、条件删除、区间删除、有序去重。
- 复杂度/边界结论：通常 O(n)、额外空间 O(1)；空表、全删、长度更新、稳定性要求必须单列。
- 全部关联：2.2应01、03、04、05。

### T06 有序顺序表的单调指针与区间缩减

- 对象：一个或多个升序数组/顺序表。
- 算法模型：二路/三路单调推进，或等长区间中位数缩减。
- 状态/不变量：被排除区间不可能含目标；每次至少推进一个边界。
- 操作：合并、查找后交换/插入、三序列求交、两序列中位数、三集合最小距离。
- 复杂度/边界结论：线性多指针通常 O(n) 或 O(m+n+...)；区间缩减可达 O(log n)；空集合、重复值、后继不存在需检查。
- 全部关联：2.2应06、08、09、11、14。

### T07 顺序表全局统计与值域辅助结构

- 对象：整数数组、候选值、值域或后缀极值。
- 算法模型：候选抵消后二次验证；布尔标记；后缀最大/最小累计。
- 状态/不变量：候选不等于已证主元素；标记只覆盖可能答案范围；后缀状态包含当前位置及其右侧。
- 操作：求主元素、最小未出现正整数、逐位置最大乘积。
- 复杂度/边界结论：以 O(n) 时间为优先；辅助空间依题目值域/输出数组口径；负数使最大乘积必须同时考虑后缀最大和最小。
- 全部关联：2.2应12、13、15。

### T08 单链表基本表示、头结点与空表

- 对象：结点地址、头指针、头结点、首元结点。
- 算法模型：由 next 链表达逻辑次序。
- 状态/不变量：物理地址可不连续；有头结点与无头结点的空表条件不同。
- 操作：表示判断、头结点作用、空表判定。
- 复杂度/边界结论：按位序定位通常 O(n)；头结点用于统一边界，不代表存在数据元素。
- 全部关联：2.3选03、09、11。

### T09 单链表局部改链与可达性不变量

- 对象：带头结点单链表、当前结点及其前驱/后继。
- 算法模型：`pre/p/r` 或等价指针保存—改链—推进。
- 状态/不变量：改链前保存未处理后继；已处理段与未处理段均保持可达。
- 操作：插入、删除尾结点、按条件删除、删除最小、地址链接、移动后继结点到表头。
- 复杂度/边界结论：已知前驱时局部改链 O(1)，定位另计；空表、首尾、连续删除与释放顺序必须检查。
- 全部关联：2.3选06、10、33、36；2.3应01、02、04。

### T10 单链表构造、拼接与连续子序列匹配

- 对象：数组到链表、两条单链表、序列模式。
- 算法模型：头插/尾插构造，尾部定位后拼接，失配后重启连续匹配。
- 状态/不变量：头插反序；拼接前第一表尾可达；连续子序列要求 B 元素相邻出现。
- 操作：建立有序链表、连接两表、判断连续子序列。
- 复杂度/边界结论：有序构造最低复杂度受排序支配；无尾指针拼接需扫描第一表；朴素连续匹配最坏可达 O(mn)。
- 全部关联：2.3选07、08、13；2.3应10。

### T11 双链表双向闭合与对称结构

- 对象：非循环/循环双链表，prior/next。
- 算法模型：插删的四连接闭合、双向遍历与对称比较。
- 状态/不变量：任一内部边满足 `x->next->prior==x` 与 `x->prior->next==x`。
- 操作：前插/后插、删除、访问前后邻结点、判断循环双链表对称。
- 复杂度/边界结论：已定位处插删 O(1)；赋值顺序必须避免用已覆盖指针取旧邻居；循环端点由哨兵闭合。
- 全部关联：2.3选15、16、17、18、20、28、32、35；2.3应11。

### T12 循环链表端点表示与 O(1) 操作

- 对象：带/不带头结点的循环单/双链表，头/尾指针。
- 算法模型：用尾指针直接得到尾与首，围绕哨兵或首元闭环。
- 状态/不变量：空表、单结点、尾 `next` 的语义由表示法唯一确定。
- 操作：判空、首尾插删、两循环表连接、删除首元、长度状态判断。
- 复杂度/边界结论：只有头指针时找尾可能 O(n)；尾指针循环单链表可 O(1) 得首元并完成多种端点操作。
- 全部关联：2.3选21—27、29、34；2.3应12。

### T13 静态链表游标与容量边界

- 对象：数组结点、游标、数据链与空闲链。
- 算法模型：用下标模拟指针。
- 状态/不变量：游标是链接，不是逻辑位序；最大容量定义时确定。
- 操作：插删、访问、空间分配。
- 复杂度/边界结论：插删无需移动元素，但定位仍需顺链；需较大连续空间且可能浪费容量。
- 全部关联：2.3选30、31。

### T14 快慢指针、长度对齐与结构性相遇

- 对象：单链表中的环、倒数位置、公共物理尾部。
- 算法模型：速度差、固定间距、长度差对齐。
- 状态/不变量：双指针距离或相对速度保持可证明关系；公共结点比较地址而非值。
- 操作：找公共结点/共同后缀、判环、找倒数第 k 个。
- 复杂度/边界结论：均可 O(n) 时间、O(1) 额外空间；需检查空链、k 非法、无公共结点、环入口条件。
- 全部关联：2.3应05、15、17、18。

### T15 有序链表归并、去重与集合运算

- 对象：递增有序单链表。
- 算法模型：二路单调指针；相等时按输出语义决定新建、保留或删除。
- 状态/不变量：两指针之前的结果已满足目标集合语义和有序性。
- 操作：有序插入、去重、构造交集、原地求交。
- 复杂度/边界结论：通常 O(m+n)，新建结果需要输出规模空间；原地求交需正确释放非交集结点。
- 全部关联：2.3选19；2.3应07、08、09。

### T16 分段逆置、旋转、拆分与重排

- 对象：顺序表分段、单链表前后半段或奇偶位结点。
- 算法模型：三次逆置；快慢找中点—逆置—拼接；奇偶拆链；成环后断开。
- 状态/不变量：每段端点清楚；改链前保存两个后继；处理后仍覆盖全部原元素且不重复不丢失。
- 操作：数组/顺序表逆置与块交换、链表拆分、循环右移、最大孪生和、首尾交替重排。
- 复杂度/边界结论：常见目标 O(n) 时间、O(1) 额外空间；奇偶长度、k 取模、断环位置是关键边界。
- 全部关联：2.2应02、07、10；2.3应03、06、14、16、20。

### T17 按访问频度自组织双链表

- 对象：含 freq 域的非循环双链表。
- 算法模型：命中后频度加一，再向前寻找稳定插入位置。
- 状态/不变量：频度递减；同频时最近访问者在前；双向链接闭合。
- 操作：Locate、摘除、重新插入。
- 复杂度/边界结论：查找加重排最坏 O(n)，额外空间 O(1)；首结点、同频段、未命中要单列。
- 全部关联：2.3应13。

### T18 值域辅助去重并释放结点

- 对象：整数单链表，按绝对值判重，已知 `|data|<=n`。
- 算法模型：值域布尔标记 + 单次链扫。
- 状态/不变量：标记集合等于此前保留结点绝对值集合；首次出现保留，后续删除释放。
- 操作：绝对值去重、结点删除、空间释放。
- 复杂度/边界结论：O(m+n) 初始化/扫描口径，辅助空间 O(n)；绝对值 0 与 n、释放后指针推进须检查。
- 全部关联：2.3应19。
