## 2. 正文提示与高价值细节

### 2.1 注意/提示/说明/辨析/易错/补充/拓展框

|---|---|---|---|---|---|

### 2.2 二级结论、隐藏重点与比较表

| 对照 | 不可省略的条件 |
|---|---|
| 顺序表随机访问 vs 按值查找 | 前者按位序，后者仍取决于查找算法 |
| 链表插删 \(O(1)\) vs 定位 \(O(n)\) | 插删处必须已定位或给出前驱 |
| 逻辑线性表 vs 顺序表/链表 | 前者是逻辑关系，后者是实现 |
| 公共元素 vs 公共结点 | 公共结点比较物理地址，不是数据值 |
| 双链表 vs 单链表 | 双链表每次修改都须维持前驱/后继双向一致 |

### 2.3 教材图表、算法、典型案例

- 顺序表图示：元素在连续地址中排列，地址/位序关系是随机访问的依据。
- 单链表图示：结点由数据域和指针域组成，逻辑次序由 `next` 链接决定，不由物理地址决定。
- 典型过程：稳定压缩、三次逆置、单链表逆置、快慢指针、公共结点对齐与重排链表。

### 2.4 数据结构专项观察项

- ADT 与实现：线性表操作定义独立于顺序或链式实现。
- 指针/下标：数组下标是连续存储的偏移；静态链表下标模拟链接，不是逻辑位序。
- 不变式：单链表改链前保存后继；双链表改链后双向闭合；双指针题中已处理区/未处理区明确。
- 终止与边界：空表、单结点、首尾结点、无前驱、容量不足、下标越界都需单列。
- 复杂度口径：定位成本与实际插删成本分开；原地算法的额外空间通常为 \(O(1)\)。

## 3. 章末收束与回扣

### 3.1 本节/本章小结或归纳总结

以“表示方式—操作代价—适用条件”为主线回看：顺序表擅长按位序访问；链表擅长已定位处插删；任何结论都需把定位、边界和附加空间说清。

### 3.2 疑难点/常见问题/自测题

1. 为什么链表结点不连续仍可表示线性关系？
2. 为什么顺序表按位序 \(O(1)\) 不代表查找任意值 \(O(1)\)？
3. 为什么链表的“插删快”必须加已定位条件？
4. 如何证明逆置过程不会丢失未处理结点？
5. 如何区分公共值与公共物理结点？

### 3.3 思维拓展

教材事实：顺序与链式存储可实现同一线性表。AI 分析：选择实现要同时考虑访问模式、定位是否频繁、容量是否变化和内存局部性；“链表一定优于顺序表”或反过来均缺少条件，不能作为 408 结论。
