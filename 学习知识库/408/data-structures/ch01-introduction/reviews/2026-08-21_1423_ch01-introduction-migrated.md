## 2. 本范围知识体系总览

1.1 解决的是“如何完整描述数据组织”的问题：

- 数据元素是数据的基本单位；数据项组成数据元素。
- 逻辑结构描述元素间关系，不关心在内存中的具体安排。
- 存储结构是逻辑结构在计算机中的实现。
- 完整数据结构还必须规定基本操作。

核心判断链：

`题干谈元素关系 → 逻辑结构`  
`题干谈数组、指针、连续地址 → 存储结构`

## 3. 核心知识、重点与难点系统讲解

### 知识点：数据结构的三要素

**教材依据：**印刷页 2—3、PDF 页 14—15。教材将数据结构概括为逻辑结构、存储结构及其基本操作。

**它解决什么问题：**既说明数据“彼此怎样关联”，又说明“怎样存进机器”，还说明“能对它做什么”。

**结构与操作：**

- 逻辑结构：如线性表、树、图。
- 存储结构：如顺序存储、链式存储。
- 基本操作：如插入、删除、查找、遍历。

**做题触发器：**看到“完整的数据结构” → 检查是否同时出现逻辑结构、存储结构、操作。

**边界：**只列“逻辑 + 存储”仍不完整；只列“数据元素及关系”也没有定义操作。

### 知识点：逻辑结构与存储结构分离

**教材依据：**印刷页 3—4、PDF 页 15—16。

**原理：**同一逻辑结构可用不同存储结构实现。例如线性表既可用顺序表实现，也可用链表实现。

**题型识别：**

- “线性、树、集合、图”通常谈逻辑关系。
- “顺序表、单链表、哈希表”通常谈具体存储或实现。
- “有序表”强调关键字之间的逻辑次序，不等同于某种特定实现。

**易错点：**把“顺序表”误当成“线性表”，或把“链表”误当成逻辑结构。

## 7. 选择题逐题完整解析

### 【选择题】1.1-01｜答案：C

题干：一个完整的数据结构通常应包含以下哪些要素？

- A. 数据元素及其存储方式
- B. 数据的逻辑结构和物理结构
- C. 数据的逻辑结构、存储结构以及在其上定义的基本操作
- D. 数据对象和数据元素之间的关系

**考查核心：**数据结构的完整定义。

- A：错。数据元素与存储方式只覆盖对象和部分物理实现，未定义操作。
- B：错。逻辑结构与物理结构仍缺少“在其上定义的基本操作”。
- C：对。逻辑结构、存储结构、基本操作三项齐全；教材解析明确给出此答案。
- D：错。只谈对象与关系，既未给出存储方式，也未给出操作。

**独立推导：**若不知道插入、删除、查找等操作如何定义，就不能据此判断同一表示上的处理规则，因此不能称完整数据结构。

**第一反应：**题干出现“完整” → 找三要素最全的选项。

**易错诱因：**B 看起来接近定义，但少了操作。

**迁移：**判断抽象数据类型时也要同时看数据对象、关系、操作集合。

### 【选择题】1.1-02｜答案：A

题干：下列四种数据结构中，哪一个是非线性数据结构？

- A. 树
- B. 字符串
- C. 队列
- D. 栈

**考查核心：**线性与非线性逻辑结构。

- A：对。树中一个结点可有多个后继，属于层次型非线性关系。
- B：错。字符串是字符的有限序列，属于线性结构。
- C：错。队列按先进先出组织，元素关系是一对一的线性关系。
- D：错。栈按后进先出组织，仍是一对一的线性关系。

**独立推导：**线性结构中除首尾外每个元素通常有唯一直接前驱和直接后继；树不满足。

**第一反应：**看到“树、图”优先判断非线性。

**易错诱因：**队列有“排队”语义，但语义特殊不等于非线性。

**迁移：**二叉树、一般树、图均是非线性；数组和链表实现什么结构不改变其逻辑分类。

### 【选择题】1.1-03｜答案：C

题干：下列选项中，属于逻辑结构的是（ ）。

- A. 顺序表
- B. 哈希表
- C. 有序表
- D. 单链表

**考查核心：**逻辑结构与具体实现的区分。

- A：错。顺序表明确指定用连续存储单元实现线性表。
- B：错。哈希表通常描述散列组织与存取实现。
- C：对。有序表强调元素关键字之间的有序关系，不限定顺序或链式实现。
- D：错。单链表明确用结点与指针实现。

**独立推导：**只要去掉某种具体物理实现后概念仍成立，才更可能是逻辑层表述。

**第一反应：**选项中是否出现“顺序、链、哈希、指针”等实现词。

**易错诱因：**“顺序表”与“有序表”只差一个字，但前者是存储结构，后者是逻辑有序性。

**迁移：**“二叉树”是逻辑结构；“顺序存储二叉树”则加入了存储实现。

### 【选择题】1.1-04｜答案：A

题干：下列关于数据结构的说法中，正确的是（ ）。

- A. 数据的逻辑结构独立于其存储结构
- B. 数据的存储结构独立于其逻辑结构
- C. 数据的逻辑结构唯一决定其存储结构
- D. 数据结构仅由其逻辑结构和存储结构决定

**考查核心：**逻辑结构、存储结构与操作之间的关系。

- A：对。同一逻辑结构可以采用顺序、链式等不同存储实现。
- B：错。存储结构是逻辑结构在计算机中的映像，不是脱离逻辑结构自行定义。
- C：错。同一逻辑结构并不唯一对应某一种存储结构。
- D：错。遗漏了定义在其上的基本操作。

**独立推导：**线性表可顺序存储也可链式存储，直接否定 C；既然存储是某逻辑结构的实现，B 也不成立。

**第一反应：**遇到“唯一”“仅由”这类绝对词，优先检查是否漏掉多实现或基本操作。

**易错诱因：**把“逻辑结构独立于存储结构”错误地双向对称化。

**迁移：**抽象数据类型与具体数据结构的关系，也遵循“抽象先于实现”。

### 【选择题】1.1-05｜答案：C

题干：在存储数据时，通常不仅要存储各数据元素的值，还要存储（ ）。

- A. 数据的操作方法
- B. 数据元素的类型
- C. 数据元素之间的关系
- D. 数据的存取方法

**考查核心：**存储结构需要表现逻辑关系。

- A：错。操作方法属于算法/基本操作定义，不是每个元素必须附带存储的关系信息。
- B：错。类型可作为实现信息，但不是本题要强调的结构性内容。
- C：对。如链表中的指针、树结点的孩子指针、图的邻接信息都用于保存元素关系。
- D：错。存取方法是访问策略，不等同于元素间的关系表示。

**独立推导：**若只存值而没有下一个结点、邻接点或数组下标关系，无法恢复结构。

**第一反应：**“不仅存值” → 想“还要存关系”。

**易错诱因：**A、D 把“如何操作/访问”与“如何表示关系”混为一谈。

**迁移：**图的邻接矩阵、邻接表正是以不同方式保存同一类顶点关系。

## 2. 本范围知识体系总览

1.2 的核心是算法定义与效率评价：

- 算法五特性：有穷性、确定性、可行性、输入、输出。
- 时间复杂度：用基本操作执行次数随输入规模的增长率衡量。
- 空间复杂度：通常指辅助空间随规模的增长率。
- 复杂度规则：
  - 串行语句取相加后的主导项；
  - 分支取最坏分支；
  - 固定次数或常量变量为 \(O(1)\)；
  - 循环变量乘常数变化，常见为对数；
  - 循环变量按单位递增直到其 \(k\) 次幂达到 \(n\)，常见为 \(O(n^{1/k})\)；
  - 嵌套循环必须逐层求和，不能机械相乘。

## 3. 核心知识、重点与难点系统讲解

### 知识点：算法五特性

**教材依据：**印刷页 4—5、PDF 页 16—17。教材列出有穷性、确定性、可行性、输入、输出。

**它解决什么问题：**区分“一个可以执行并终止的算法”与“只有想法或程序片段的描述”。

**做题触发器：**看到“算法应具有什么性质” → 直接核对五特性，不把可读性、可靠性、正确性混入定义。

**边界：**正确性、健壮性、可读性影响算法质量，但不是该教材此处定义的五特性。

### 知识点：时间复杂度与空间复杂度

**教材依据：**印刷页 5—8、PDF 页 17—20。

**原理：**

- 时间复杂度关注规模足够大时的主导增长项，忽略常数系数和低阶项。
- 空间复杂度关注算法运行所额外申请的辅助空间，不把输入本身占用错误计入辅助空间。
- \(O(n^2)\) 是渐近上界记号；具体题目若以教材标准答案表述“与 \(n^2\) 成正比”，应按题册语境选 C，但概念上不应把 \(O\) 严格等同于 \(\Theta\)。

### 知识点：循环、递归的复杂度判定

**教材案例：**印刷页 9—12、PDF 页 21—24，对倍增循环、递归和变上界嵌套循环给出分析。

**方法：**

- `i *= 2`：写 \(2^t\) 与 \(n\) 的不等式。
- `i++` 且 `i^k <= n`：写 \(t^k\le n\)。
- 外层倍增、内层长度为当前 `i`：求几何级数 \(1+2+\cdots\)，而不是 \(n\log n\)。
- 递归 `f(n/2)`：递归深度为 \(O(\log n)\)。
- 递归 `f(n-1)`：递归深度为 \(O(n)\)。

## 4. 教材二级结论、隐藏重点和典型案例

- 时间效率不等于真实 CPU 运行秒数；它以基本操作次数的渐近增长反映。
- 评价算法不应只看时空复杂度，也要考虑正确性、可读性、健壮性等。
- 同一逻辑结构采用不同存储方式，操作效率可以不同：顺序表中间插删常为 \(O(n)\)，链表在已定位时插删可为 \(O(1)\)。
- 变上界嵌套循环要展开成求和。  
  例如外层 `i*=2`、内层运行 `i` 次，总代价为 \(1+2+\cdots+2^k=O(n)\)，不是 \(O(n\log n)\)。

## 5. 重点难点易错点专项

| 场景 | 错误判断 | 正确判断条件 |
|---|---|---|
| \(O(1)\) 空间 | “不占任何空间” | 指辅助空间不随输入规模增长 |
| 复杂度比较 | 看常数或负低阶项 | 只看主导增长阶 |
| 有分支的代码 | 把两支相加 | 最坏时间取最大分支 |
| 双循环 | 一律外层 × 内层 | 内层上界是否依赖外层 |
| `i*=2` | 误作 \(O(n)\) | 解指数不等式 |
| `i^2<=n` | 误作 \(O(n)\) | 解幂次不等式 |
| `sum += ++i` | 误作 \(O(n)\) | 利用等差求和到达阈值 |
| 递归 | 只看函数式 | 看递归规模变化与单层成本 |

## 9. 应用题逐题完整解析

### 【应用题】1.1-应用 01

题干：对于两种不同的数据结构，逻辑结构或物理结构一定不相同吗？

**题目要求与输入状态：**判断“不同数据结构”是否必然要求逻辑结构或物理结构不同。

**解题思路：**数据结构的区分不只来自逻辑与存储表示，定义在结构上的操作、约束与效率也可造成区别。

**关键过程：**

- 二叉树与二叉排序树都可采用二叉树的逻辑表示和链式存储表示。
- 二叉排序树额外具有左子树关键字小于根、右子树关键字大于根的有序约束。
- 在查找操作上，一般二叉树可能需要遍历，二叉排序树可利用有序性进行方向选择。

**结果：**不一定。两种不同数据结构的逻辑结构和物理结构可以相同，但其数据约束、操作语义或操作效率可不同。

**复杂度与边界：**

- 一般二叉树查找最坏 \(O(n)\)。
- 二叉排序树查找平均可为 \(O(\log n)\)，但退化为链时最坏仍为 \(O(n)\)。
- 不要把“二叉排序树”误称为“必然 \(O(\log n)\)”；是否平衡影响最坏复杂度。

**迁移：**比较两个结构时，不要只比较存储图；还要比较不变量、允许操作与性能目标。

### 【应用题】1.1-应用 02

题干：举例说明对相同的逻辑结构，同一种运算在不同存储方式下实现时，其运算效率不同。

**题目要求与输入状态：**给出同一逻辑结构、同一种操作、两种存储实现及效率对比。

**解题思路：**选择线性表，分别用顺序存储和链式存储实现。

**关键状态/过程：**

- 顺序表：元素连续存放。中间插入一个元素，插入位置后的元素需后移。
- 链表：节点以指针相连。若已经定位到插入位置的前驱，只需修改两个链接关系。

**AI 改写伪代码：**

```text
顺序表在第 i 位插入 x：
for j = n downto i:
    A[j + 1] = A[j]
A[i] = x
```

```text
单链表在 p 后插入新结点 s：
s.next = p.next
p.next = s
```

**结果与复杂度：**

| 存储方式 | 按序号访问 | 已定位处插入/删除 |
|---|---:|---:|
| 顺序表 | \(O(1)\) | \(O(n)\) |
| 链表 | \(O(n)\) | \(O(1)\) |

**核查与边界：**

- 链表“插入 \(O(1)\)”以已知 `p` 为前提；若要先找第 \(i\) 个位置，总时间为 \(O(n)\)。
- 顺序表尾部插入在容量足够时可为 \(O(1)\)，中间位置才一般为 \(O(n)\)。
- 顺序表扩容时可能有一次 \(O(n)\) 复制成本。

**迁移：**看到“随机访问多”偏向顺序存储；看到“已定位后的频繁插删”偏向链式存储。

### 【应用题】1.2-应用 01

题干：分析下列各程序段，求出算法的时间复杂度。

#### （1）

```c
i=1; k=0;
while(i<n-1) {
    k=k+10*i;
    i++;
}
```

**输入状态：**规模为 \(n\)，`i` 从 1 每轮加 1。

**关键状态：**

| 循环轮次 | `i` 进入循环时 | 主体是否执行 |
|---|---:|---|
| 1 | 1 | 是（若 \(n>2\)） |
| 2 | 2 | 是 |
| … | … | … |
| 最后 | \(n-2\) | 是 |
| 结束 | \(n-1\) | 否 |

**独立推导：**主体共执行 \(n-2\) 次，因此 \(T(n)=\Theta(n)\)。

**教材对照：**教材解析同样给出 \(n-2\) 次、\(O(n)\)。

**空间：**`i,k` 为常数个变量，辅助空间 \(O(1)\)。

**边界：**当 \(n\le2\) 时循环 0 次，不影响渐近结论。

#### （2）

```c
y=0;
while((y+1)*(y+1)<=n)
    y=y+1;
```

**输入状态：**`y` 从 0 按 1 增长，停止条件由平方与 \(n\) 比较。

**关键状态：**

| 执行次数 \(t\) | 循环后 `y` | 条件关系 |
|---:|---:|---|
| 0 | 0 | \(1^2>n\) 时直接结束 |
| 1 | 1 | \(1^2\le n\) |
| \(t\) | \(t\) | \(t^2\le n\) |
| 结束 | \(\lfloor\sqrt n\rfloor\) | \((y+1)^2>n\) |

**独立推导：**循环 \(t\) 次须满足 \(t^2\le n\)，故 \(t=\Theta(\sqrt n)\)。

**教材对照：**教材给出 \(T(n)=O(n^{1/2})\)。

**空间：**辅助空间 \(O(1)\)。

**迁移：**若把条件改为 \((y+1)^3\le n\)，则为 \(O(\sqrt[3]n)\)。

#### （3）

```c
for(i=0; i<n; i++)
    for(j=0; j<m; j++)
        a[i][j]=0;
```

**输入状态：**待置零的二维数组 `a`，共有 \(n\) 行、\(m\) 列。

**关键状态：**

- 外层每个 `i` 固定时，内层完整访问 \(j=0,\ldots,m-1\)。
- 每个数组位置 `a[i][j]` 恰赋值一次。
- 总赋值次数为 \(n\times m\)。

**独立推导：**  
\[
T(n,m)=\sum_{i=0}^{n-1}\sum_{j=0}^{m-1}1=nm=\Theta(nm)
\]

**教材对照：**教材答案给出 \(O(mn)\)，与 \(O(nm)\) 等价。

**空间：**

- 不计已存在或作为输出的数组 `a`：辅助空间 \(O(1)\)。
- 若题目问整个数组存储量：\(\Theta(nm)\)。

**边界：**\(n=0\) 或 \(m=0\) 时不执行；不改变复杂度表达式。

## 12. 最终压缩总结

### 必须掌握

- 算法五特性：有穷性、确定性、可行性、输入、输出。
- \(O(1)\) 空间指辅助空间不随规模增长，不是“零空间”。
- 倍增循环：\(\log n\)。
- 逐一增加直到平方/立方阈值：\(\sqrt n/\sqrt[3]n\)。
- 外层倍增、内层为当前外层值：几何级数，常为 \(O(n)\)。
- 已定位链表插删 \(O(1)\)；顺序表按下标访问 \(O(1)\)。

### 最值得复习的教材案例

- 线性表顺序/链式实现的效率比较。
- 变量参与循环条件时，先列不等式再解次数。
- 递归 `n/2` 与 `n-1` 的深度对比。

## 3. 统一题型池：各类结论先行

### T1 完整数据结构与关系表示

- 对象：逻辑结构、存储结构、基本操作。
- 识别信号：“完整数据结构”“不仅存储元素值，还要存储什么”。
- 方法：按关系—表示—操作逐项检查。
- 边界：存取方法不等于元素关系；逻辑结构加存储结构仍可能漏掉基本操作。
- 关联：1.1-01、1.1-05。

### T2 逻辑分类与抽象—实现分层

- 对象：逻辑结构、存储结构、ADT；抽象关系到具体存储是一对多映射。
- 识别信号：线性/非线性、有序表/顺序表/单链表、独立/唯一决定。
- 方法：删去顺序、链式、散列、指针等实现词，再判断概念是否仍成立。
- 边界：逻辑结构可独立于某个具体实现，不表示存储结构能脱离逻辑对象存在。
- 关联：1.1-02、1.1-03、1.1-04。

### T3 结构约束、操作语义与存储效率

- 对象：相同或相近逻辑结构的约束、操作和实现。
- 方法：按结构形态—约束—操作语义—定位成本—操作成本比较。
- 边界：链表插删`O(1)`需已定位；普通BST退化时最坏仍为`O(n)`。
- 关联：1.1-应用01、1.1-应用02。

### T4 算法合法性与评价维度

- 对象：算法五特性与质量指标；状态链为输入—有限且确定的步骤—至少一个输出。
- 方法：先核对有穷、确定、可行、输入、输出，再区分正确性、可读性、健壮性。
- 边界：时空效率不是唯一指标；允许空间换时间。
- 关联：1.2-01、1.2-02。

### T5 渐近语义、主导项与辅助空间

- 对象：`O/Theta`、增长阶、辅助空间。
- 方法：去常数、去低阶；空间题补“辅助”；区分精确次数、增长阶和实测时间。
- 边界：大O是渐近上界；输入空间与额外辅助空间不能混算。
- 关联：1.2-03、1.2-04、1.2-05。

### T6 独立上界、路径选择与乘法计数

- 对象：互斥分支、固定或独立上界循环。
- 方法：结合分支条件判断实际可达路径；按题目口径取最好/最坏/实际路径；独立嵌套相乘。
- 边界：数组总存储与算法辅助空间分开。
- 关联：1.2-08、1.2-09、1.2-14、1.2-应用01（1）、（3）。

### T7 倍增状态与对数迭代

- 对象：按常数倍更新的循环变量；第`t`轮状态约为初值乘`c^t`。
- 方法：建立`c^t`与终止阈值的不等式。
- 边界：初值、严格不等式和取整只影响常数；教材中的`log`默认底2。
- 关联：1.2-06、1.2-12。

### T8 幂次或累加阈值反解

- 对象：逐次增加变量、幂次阈值、累计量。
- 方法：写出执行`t`次后的`t^k`或`1+...+t`，直接反解终止量与`n`的关系。
- 边界：平方、立方和三角数属于同一反解框架，但状态函数不同。
- 关联：1.2-07、1.2-15、1.2-16、1.2-应用01（2）。

### T9 单分支递归调用链

- 对象：递归调用次数、规模缩减、栈深度。
- 方法：先数源代码中的递归调用次数，再分析规模序列。
- 边界：`2*Func(n/2)`只有一次递归调用；乘2不是第二个递归分支。
- 关联：1.2-11、1.2-13。

### T10 依赖上界与级数求和

- 对象：内层成本随外层变量变化的嵌套循环。
- 方法：先列每轮成本序列，再识别等差和、几何和或其他级数。
- 边界：外层倍增、内层到当前值的总和常为线性；外层到根号`n`、内层到`i`的总和也是线性。
- 关联：1.2-10、1.2-17、1.2-18。
