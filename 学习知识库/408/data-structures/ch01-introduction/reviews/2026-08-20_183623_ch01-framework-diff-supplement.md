## 5. 易被忽略的二级结论、隐藏条件、图表与边界

| 位置 | 教材事实 | 容易漏掉的条件或边界 |
|---|---|---|
| 印刷页 2 / PDF 14 | 抽象数据类型 ADT 是“数据模型 + 定义在其上的一组操作”；规定取值范围、结构形式和可执行操作集合 | ADT 是抽象层，不等同于顺序表、单链表等具体实现 |
| 印刷页 2 / PDF 14 | “算法设计取决于逻辑结构，算法实现依赖存储结构” | 逻辑与存储“密不可分”不等于逻辑结构唯一决定存储实现 |
| 页脚注释，印刷页 2 / PDF 14 | 设计与实现的概念区别应在后续章节逐步理解 | 本章只建立分层，不应抢先把后续实现细节当已讲结论 |
| 图 1.1，印刷页 2 / PDF 14 | 逻辑结构按线性/非线性展开；线性包括受限线性表、线性表推广，非线性包括集合、树、图 | 图中“栈和队列、串、数组”是逻辑层分类语境，不能直接替换为具体存储实现 |
| 图 1.2，印刷页 2 / PDF 14 | 四类基本结构关系：集合、线性、树形、网状 | 图是静态关系分类，不是算法过程或状态变化图 |
| 印刷页 3 / PDF 15 | 存储结构分顺序、链式、索引、散列 | 旧版重点只放顺序/链式；索引和散列在本章仅作概念性列举，不展开算法细节 |
| 印刷页 5 / PDF 17 | 实际运行时间受硬件、编译器等影响，故用渐近复杂度描述趋势 | 复杂度不是实测 CPU 秒数 |
| 印刷页 5—6 / PDF 17—18 | 最好、最坏、平均时间复杂度都与输入初始状态有关 | 未说明分布时，不能把平均情况当默认；题目问“最坏”才取最大频度 |
| 印刷页 6 / PDF 18 | 加法规则取高阶项，嵌套代码适用乘法规则 | 变上界嵌套循环仍需先求和，不能机械相乘 |
| 印刷页 6 / PDF 18 | 空间复杂度只关注随规模变化的辅助空间 | 指令、常数、输入数据通常不作为随 \(n\) 变化的辅助空间；原地工作可为 \(O(1)\) |
| 印刷页 11—12 / PDF 23—24 | 循环主体变量参与循环条件、与循环条件无关，是复杂度分析的两类归纳路线 | 先分类型，再决定列不等式、逐层计数或递推 |

## 6. 数据结构专项观察

| 观察项 | 本章实际支持的内容 | 结论 |
|---|---|---|
| ADT 与实现分层 | ADT、逻辑结构、存储结构、数据运算均有明确定义 | 应补“抽象模型—逻辑关系—存储实现—操作”的层级链 |
| 图示/状态变化 | 图 1.1、1.2 为结构分类静图；复杂度部分有循环变量与执行次数表 | 本章无栈、队列、链表链接的动态状态演示 |
| 下标与返回值 | 顺序查找片段使用 `A[0...n-1]`，从 `i=n-1` 递减，返回 `i` | 下标起点为 0；AI 分析：查找失败时会返回 -1 |
| 终止与不变式 | 查找循环条件为 `i>=0 && A[i]!=k` | AI 分析：循环头可保持“已检查的后缀均不等于 k”；终止于找到 k 或 i 越过 0 |
| 空指针、哨兵、前驱 | 逐页核验后未发现 | 不应为本章编造指针/哨兵/前驱知识 |
| 递归返回与副作用 | 本章无完整递归函数实现，仅在章末要求比较递归与非递归方法 | 不应补充具体递归代码为教材原文 |
| 复杂度口径 | 频度、基本运算、最好/最坏/平均、加法/乘法规则、辅助空间均有明确表述 | 比旧版“结论式复杂度”更完整 |
| 源码与可执行实现 | 教材给出用于分析的程序片段和伪代码，不是完整可编译程序 | AI 分析：实现时仍需补类型、输入约束、边界处理；这属于工程补充，不是教材原文 |

## 8. 思维拓展：教材事实与 AI 分析

| 项目 | 教材事实 | AI 分析 |
|---|---|---|
| 题目 | 求斐波那契数列，比较递归算法和非递归算法的时间复杂度 | 教材未给具体代码，因此下列结论以“标准朴素实现”为假设 |
| 递归法 | 教材只说明递归是常用方法之一 | 若 `F(n)=F(n-1)+F(n-2)` 且不记忆化，递归调用树重复计算子问题，时间为 \(\Theta(\varphi^n)\)，可宽松写 \(O(2^n)\)，递归栈为 \(O(n)\) |
| 非递归法 | 教材只说明非递归是常用方法之一 | 若从 \(F(0),F(1)\) 迭代推进到 \(F(n)\)，每轮常数次更新，时间 \(\Theta(n)\)，辅助空间 \(O(1)\) |
| 反例/边界 | 教材未展开 | 若递归法加记忆化，时间也可降为 \(\Theta(n)\)，空间通常为 \(O(n)\)；不能把“递归”本身等同于指数时间 |
| 408 联系 | 本章训练复杂度分析 | 关键是数递归调用分支、识别重复子问题，并区分时间与递归栈空间 |
