# 考研政治答题思维与知识遗漏复盘

政治复盘先判断“知识不会、概念边界混淆，还是题目决策错误”，再训练选择题逐项判断、材料映射和分析题规范表达。年度大纲、时政和预测资料必须保留版本边界。

把本地政治知识库作为课程问答的第一检索层。知识库优先是指在判断前主动利用相关知识卡、概念边界、答题方法、真实薄弱点和既有复盘，不是把任意题目强行匹配为题册原题，也不能用旧记录替代年度大纲或时政的当前核验。

## 两阶段产出合同

本合同适用于成组、专题范围或整套政治题复盘。单题、单个概念和分析题局部问答使用后文的课程内容归纳与确认后增量协议，不要求先生成整套复盘，但不得借单题模式拆散本应完整覆盖的范围。

1. **阶段一：完整复盘成品。**成组、专题范围或整套任务先按 [references/politics_review_prompt.md](references/politics_review_prompt.md) 的完整第一版结构在对话中输出；答案表、知识卡或拟沉淀清单不能替代完整成品。
2. **阶段二：基于已接受成品整理。**仅在用户明确接受阶段一并确认保存后进行；先归档完整正文，再提炼知识卡、概念边界、答题方法和真实个人薄弱点。
3. 不得绕过阶段一直接从题册、解析或讲义写知识库；阶段二不得把新生成的摘要冒充用户已接受的第一版。
4. 成组/整套题分批时，每批先完成对应范围的完整第一版；全部批次结束后输出总覆盖表、版本边界、修正记录和缺口审计。

长篇 Stage A 允许在同一 Codex 任务中按“传输分段”连续输出。传输分段不是安全题量分批，也不是多个 review：必须使用同一 `dossier_id`、明确正文边界和连续段序，只能在最后一段完成段清单与总覆盖审计后请求验收。完整执行 [references/review-artifact-protocol.md](references/review-artifact-protocol.md)。

### Stage B 正文完整性门

写入前必须从当前任务或明确的已接受文件取得用户实际确认过的 Stage A 完整正文。若正文分段交付，必须先恢复被验收的各段 revision，按连续段序拼成一个 review，并生成相邻 `.review-manifest.json`。归档不得压缩、改写、重排栏目或用知识卡摘要重建；只允许在正文外增加归档元数据和 Stage B 执行记录，并逐段及整体验证规范化正文哈希。若完整正文不可取得，停止并报告归档缺口，不得把摘要冒充 accepted review。

## 先统一题型池，再逐题复盘

章节、专题、整套或跨资料复盘必须先登记用户指定的全部显式题目，再把真题、肖秀荣1000题、肖八肖四及其他明确题集放进一个统一题型池；不得按每本书各自分类，也不得先逐题分析、最后才补题型总结。

每道显式题只有一个主题型，可附理论/史实对象、题干限定词、概念边界、材料映射、干扰项错误机制、分析题组织方式和版本性质等次级标签。先输出各题型的识别信号、优先核对内容、规范结论、排除或组织方法、适用边界、常见变式和全部关联题号；随后按原资料和原题号顺序逐题完整解析，最后审计显式题目登记数、主题型归类数和详解数一致。

肖秀荣背诵提纲、教材/讲义中的示例、材料案例和老师示范默认只作为知识边界与题型方法提炼的隐式证据。每个实际用于总结的示例都在内部关联到统一题型池的一个主题型，但不显示逐例题号、题面、完整解析或示例覆盖率，也不计入显式题目分母；用户明确点名某个示例时才显式展开。年度、时政和预测边界仍按来源优先级单独核验。

新做的成组/整套显式题默认单次不超过 25 道编号题或 35 个小问，超出时按原资料连续拆分。只有既有 accepted 范围的纯分类追补可以例外整套处理：每题/小问必须有可直接定位、可复读的完整 accepted 解析，本轮只能登记、分类、审计和短链；任一解析不可定位时，必须分批恢复并重新验收。无显式题目的提纲章节不适用该数值限制，但仍须保留零分母审计。

## 预建学科模块

政治按马原、毛中特、新思想、史纲、思修法基、形势与政策及当代六个模块预建骨架。先用 `catalog.json` 的学科别名和关键词路由；`organization_status: skeleton` 仅表示目录存在，不代表该学科或章节已整理。

每个模块的 `outline_framework.md` 只是肖秀荣提纲整理的 `reserved-empty` 路由框架，不代表已读取、已整理或已掌握。只有在具体章节复习中实际核对肖秀荣提纲、输出完整第一版并经用户验收和授权后，才可填充对应增量。

对未整理模块，按当前题目、肖秀荣提纲相关页、教材/讲义、正式材料和清楚标识的独立判断作答。时政、年度大纲和预测仍必须核日期与来源，不因骨架存在而变成稳定事实。课程内容回答执行具体归纳和双重确认；确认后写入对应模块并增加 `confirmed_increment_count`，但单题或单个知识卡不能升级为 `organized`。只有满足完整第一版、提纲覆盖、版本边界和覆盖审计的范围才能升级。

## 先判定是否属于课程内容

- **触发归纳与归档提醒：**政治概念、原理、史实、地位词和概念边界，选择题逐项判断，材料—原理映射，分析题组织，知识遗漏、审题错误和答题策略。
- **不触发：**是否已整理/保存/完成、文件路径与结构、覆盖数量、更新时间、任务进度、资料是否存在、skill 触发和保存规则、知识库管理。这些问题直接回答，不出现“待确认”或归档邀请。
- **混合问题：**只归纳可供复习的政治知识或答题方法；文件、进度、来源管理和规则说明不得进入知识卡或个人画像。

## 工作流

1. 提取来源、年份、学科、题型、材料、全部选项/小问、用户答案与理由、标准答案和解析；缺失内容不猜。
   - 若任务是章节、专题或背诵提纲整理，先按肖秀荣手册的实际目录、栏目名和页码冻结知识范围；不得凭通用教材章号猜测手册范围。
2. 通过 `catalog.json` 的学科、概念、限定词、年份和材料特征路由模块，并在判断前检索相关 `knowledge_cards.md`、`concept_boundaries.md`、`answer_methods.md` 和 `user_weaknesses.md`；不能因为模型本身知道该概念就跳过检索。
3. 若题面、年份题号或材料结构表明它与已接受复盘中的原题或案例高度相似，主动检索 `reviews/` 并读取匹配段落；没有实质匹配时不得硬套题号、材料或旧解析。
   - 相似检索还要比较理论/史实对象、地位词、主体、时间、范围、概念边界、材料映射、题干限定词和答题组织；CURRENT/PREDICTION 与不同年度内容不得因主题相近而并入 STATIC 条目。
4. 检索后、正式解答前必须判定并按需显示“已整理命中提醒”；该提醒只说明来源状态，不是归档邀请或写入授权。
   - `EXACT_ACCEPTED`：资料及年份、政治模块、题型/题号、材料、理论或史实对象、限定词和版本性质均对应同一条已接受复盘；CURRENT/PREDICTION 还必须匹配日期边界。先读取精确段落，再提示：`已命中既有整理：{资料/年份/模块/题号或范围}。本次先以该复盘为底稿，再回答你当前问法。`
   - `RELATED_ACCEPTED`：不是同一道原题，但理论对象、概念边界、地位词、材料映射、限定词辨析或答题组织可迁移。读取相近条目后提示：`已命中相关整理：{知识点/方法/概念边界}；不是同一道原题。`
   - `DRAFT_OR_SKELETON`：只有模块骨架、reserved-empty 提纲框架、待验收草稿、未接受复盘或未经核实的旧产物。不得说“已整理”；必要时只说明“已有路由骨架/待验收草稿，但没有可复用的已接受整理”。
   - `NO_HIT`：没有实质匹配时不显示命中提醒，按当前题目和有效来源独立作答。
   - `CONFLICT`：既有接受复盘与当前年度、正式表述、时政事实、地位词或材料结论冲突时，先说明冲突，再按来源优先级和当前日期复核。
   - 同题号但资料、年份、模块、材料或 STATIC/SYLLABUS/CURRENT/PREDICTION 性质不同，不得判为精确命中。提醒不得暴露绝对路径、提前倾倒旧答案、暗示用户薄弱或声称本轮已保存。
5. 把内容标为 STATIC、SYLLABUS、CURRENT 或 PREDICTION；未核实的年度大纲和时政不得用确定口吻，旧知识库记录不能替代当前来源核验。
6. 利用检索内容辅助识别考点和概念边界，再独立判断题干限定词、答案方向与置信度并比较用户和解析。等价的不同论证可以保留；若选项真假、地位词、主体、时间、概念边界或材料映射不一致，必须回查匹配归档，必要时核对正式或当前来源。
7. 将错误分为 Level 1 知识遗漏、Level 2 概念/边界混淆、Level 3 审题/选项/材料决策错误，并给出对应学习动作。用户主动说出正确原理、地位词或材料映射，不自动证明“已掌握/不薄弱”，也不自动构成薄弱点；结合语气、依据和上下文判断，证据不足时只标为 `候选薄弱点（待确认）`。
8. 完整读取 [references/politics_review_prompt.md](references/politics_review_prompt.md)，执行其“完整第一版输出结构”和对应学科与题型模板；若需要传输分段或归档完整复盘，同时完整读取 [references/review-artifact-protocol.md](references/review-artifact-protocol.md)；章节/专题整理还必须先完整读取肖秀荣提纲协议。
9. 每题提炼“题干出现什么 → 先核对什么 → 如何排除或组织答案”，并标明适用边界。
10. 单题或单点课程问答必须以“本次政治问题归纳（待确认，尚未保存）”收尾，包含学科/题型、资料性质与日期、核心知识或原理、概念边界、材料映射/选项判断、答题方法、错误层级、掌握度判断、建议归档、拟写入内容、`归并判定（预判）`和`拟归并目标`；使用 `等价 / 补充 / 相邻 / 冲突 / 全新 / 无需新增`。精确命中且没有可复用新增通常判为 `等价` 或 `无需新增`；新增讲法或边界判为 `补充`；核实后的不一致判为 `冲突`。
11. 成组或整套阶段一复盘必须以“本次政治复盘归纳（待确认，尚未保存）”收尾，概括范围、版本边界、覆盖、知识卡/概念边界/答题方法、真实个人错误和待核实项，并对每个派生逻辑条目给出归并预判与目标；该归纳不能替代完整第一版。分段时仅最后一段出现该验收收尾，并附完整段清单。
12. 两种模式都要询问归纳是否准确及是否同意归档。只有用户同时认可当前归纳准确并明确同意归档后，才完整读取 [references/storage-protocol.md](references/storage-protocol.md)，复核目标并执行五态归并；若类别或目标发生实质变化，必须展示修订归纳并重新等待双重确认。完整 review/addendum 还必须通过 [references/review-artifact-protocol.md](references/review-artifact-protocol.md) 的前端发布门；缺成对 manifest、校验失败或替代关系未登记时不得报告已归档/已完成。

## 题型重点

- 单选：限定词、正确项依据和三个干扰项的具体错误。
- 多选：A—D 独立判断真假与是否符合题意，再诊断多选、少选或误选。
- 马原：概念、原理、条件、相近原理区别和材料识别。
- 史纲：时间、主体、背景、性质、结果、意义和前后关系。
- 新思想/毛中特：逐字核验地位词、主体、目标、任务与保障。
- 思修法基：定义、分类、上下位关系和法律术语边界。
- 分析题：设问、原理、材料关键词、逐条映射、分点答案和用户答案修正。

## 证据与保存边界

- 事实与规范表述优先级：真题/正式材料 > 官方大纲和权威教材 > 正式答案/权威解析 > 肖秀荣背诵提纲 > 用户解析 > 其他老师方法 > AI 推断。
- 肖秀荣提纲用于组织复习重点，不自动等于官方原文；与更高优先级来源冲突时不得为了保持提纲原貌而覆盖正式依据。
- 预测题不是官方命题依据；时政结论必须标注日期和来源性质。
- 通用易错点不能写成用户弱点；AI 答错时说明错误所在层级。
- 未明确确认时不写文件；若确认保存但当前对话没有已接受正文，请索要正文或文件，不凭记忆重建。
- 对单题增量，双重确认后只更新知识卡、概念边界、答题方法或真实个人弱点，不新建整套 review；对成组/整套复盘，仍严格执行完整第一版的两阶段合同。
- 课程内容问答必须给出具体归纳；管理和状态问题不得追加“待确认”或归档提醒。
- 能独立说明原理、条件、材料对应和相近概念边界，可视为本轮掌握信号；猜测、犹豫、反复确认、自我纠正、前后矛盾、依赖提示或说不清材料依据，只能形成候选薄弱点。
- 若不明确，询问“这是你已经掌握后的总结，还是你仍容易混淆、希望记录为薄弱点？”候选状态不得写入；用户回答后必须修订完整归纳并重新取得准确性与归档双重确认。不得保存“用户不薄弱/已掌握”的负面画像。

## 记录时间与活动日志

每个成功归档的逻辑条目必须带实际归档时间：Markdown 写 `记录时间：YYYY-MM-DD HH:mm:ss +08:00`，元数据写 ISO `recorded_at`，统一使用 Asia/Shanghai（中国标准时间，东八区）。再向 `E:\桌面\学习\考研\学习知识库\activity_log.jsonl` 追加记录，包含政治模块、STATIC/SYLLABUS/CURRENT/PREDICTION、资料年份或核验日期、题号/范围、知识或方法摘要及源文件。

每份完整 review 或 accepted addendum 必须有且仅有一条 accepted-review 容器记录，并用 `derived_record_ids` 关联本次真实派生增量。每个派生 Markdown 条目自身都要写完整时间，不能只在父标题写日期。

只有双重确认且写入成功后才登记；去重未新增、候选薄弱点和只讨论未归档的内容不登记。时政发生日期、来源发布日期、核验日期和知识库记录时间必须分开。
