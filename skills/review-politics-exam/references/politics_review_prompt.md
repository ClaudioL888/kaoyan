# 考研政治答题思维与知识遗漏复盘提示词

请围绕本次提供的考研政治真题、章节题、模拟题、材料题或分析题进行复盘。政治的目标不是把讲义重新抄一遍，而是区分知识遗漏、概念边界混淆和答题决策错误，并形成下一次可执行的判断规则。

## 任务变量

~~~text
本次范围：<年份/章节/题号/分析题小问，必填>
来源：真题 / 1000题 / 肖八肖四 / 肖秀荣背诵手册 / 其他模拟或讲义
学科：马原 / 史纲 / 毛中特与新思想 / 思修法基 / 时政
用户答案与思路：<如有，原样提供>
标准答案/官方解析：<如有>
本次重点：<可选，如地位词、多选、材料映射、知识遗漏>
输出模式：完整教学 / 先给提示不公布答案
~~~

## 一、先核对资料和版本

1. 提取来源、年份、学科、章节、题型、题干、材料、全部选项/小问、用户答案、用户思路、标准答案和解析。
2. 图片、扫描件或题干不完整时，明确列出缺口，不猜题干、选项、史实或时政结论。
3. 把事实标记为 STATIC（稳定理论）、SYLLABUS（年度大纲）、CURRENT（年度时政）或 PREDICTION（模拟/预测）。2027 正式大纲或当年时政未核实时，不使用确定口吻。
4. 若答案册、解析与题干或正式材料冲突，分别列出各方依据和置信度，不能为了迎合答案修改逻辑。
5. 章节、专题或知识大纲整理必须按 `xiao-outline-protocol.md` 核对肖秀荣背诵手册，先依据手册实际目录、栏目和页码冻结范围；不得凭通用教材章号猜测，也不得把老师资料写成官方依据。

## 二、先独立作答

在比较用户答案和解析前，先给出：

- AI 独立答案；
- 学科、题型和核心考点；
- 题干真正要求判断的对象；
- 关键词和限定词；
- 置信度以及仍需核实的内容。

## 三、错误分层

先判断错误属于哪一层：

### Level 1：知识遗漏

完全不知道、历史事实缺失、术语不会、年度时政未接触。输出“缺失知识点—最小补充—复现动作”，不要默认重听整章。

### Level 2：概念边界混淆

知道大概内容，但混淆本质/现象、根本/直接、主要/首要、中心/核心、保证/条件、历史事件性质或两个相近原理。输出 A 与 B 对照、关键词、反例和变式。

### Level 3：答题决策错误

知识基本会，但审题、限定词、材料映射、多选选择、干扰项排除或分析题组织出错。输出“题干信号—判断顺序—排除规则”。

标签可组合：

~~~text
K 知识遗漏       C 概念混淆       B 边界错误       R 关系错误
H 历史事实       S 地位词错误     T 术语搭配       M 材料理解
Q 审题           O 干扰项         X 多选决策       CA 时政
MEM 记忆遗漏     CARE 粗心        PR 原理定位      KP 分析题漏点
MAT 材料结合     ORG 答案组织      EXP 表达不规范   OFF 偏题
~~~

## 四、单选题

按以下顺序：

1. 题干问的是原因、表现、意义、性质、本质、措施、依据还是其他；
2. 标出“根本、直接、主要、首要、核心、中心、本质、关键、保证”等限定词；
3. 给出正确选项依据；
4. A、B、C、D 逐项判断：正确/错误/表述正确但不符合题意；
5. 对错误项具体归类：知识错误、主体错误、时间错误、地位词错误、因果倒置、范围扩大、绝对化、材料对应错误、答非所问；
6. 说明用户是在知识层、边界层还是决策层出错；
7. 给出一条下次遇到同类题的规则。

## 五、多选题

不得只报组合答案。先判断题干限制，再逐项独立判断：

~~~text
A：正确/错误/正确但不符合题意，理由……
B：……
C：……
D：……
~~~

重点检查：

- 把“正确表述”误当成“符合题意”；
- 把可能扩大成必然；
- 把直接原因当根本原因；
- 主体、时间、范围或地位词错误；
- 多选：不敢选抽象但正确的项；
- 少选：被绝对化、无中生有或答非所问的项干扰。

最后明确用户是多选、少选、误选还是题干理解错误。

## 六、五个学科的专项逻辑

### 马原

按“概念 → 原理 → 条件 → 与相近原理区别 → 材料关键词 → 常见错误表述”讲解。不能只说“这是辩证法/认识论”，必须说明材料中什么事实触发了哪个原理。

### 史纲

建立“时间—主体—背景—性质—结果—意义—前后关系”。错题必须判断究竟错在年代、人物、事件、性质、首次/标志、意义还是因果关系；必要时生成局部时间线。

### 毛中特与新思想

逐字核验地位词、主体、目标、任务、保障和战略支撑。出现“根本、核心、首要、中心、本质、关键、保证”时，不能用模糊的“政治上正确”带过。

### 思修法基

给出定义、分类、上下位关系、法律术语和相近概念边界；说明为什么选项虽然价值方向正确，仍可能不符合教材表述。

### 时政

核对年份、事件和权威表述；明确知识截至时间；把官方事实、老师概括和预测材料分开。没有可靠年度来源时，标注待核实，不编造。

## 七、分析题

先识别设问：为什么、如何理解、体现什么原理、意义是什么、如何做、依据是什么。然后按：

1. 学科与原理定位；
2. 材料关键词；
3. 原理—材料逐条映射；
4. 分点答案；
5. 用户答案评价。

推荐答案结构：

~~~text
原理/观点
→ 对原理的准确解释
→ 材料中对应的事实或句子
→ 回答设问并形成结论
~~~

评价用户答案时分别检查：原理是否正确、是否漏关键点、是否结合材料、是否分点、政治术语是否规范。输出“保留内容—必须修改—可提升—最小修改版”，不要只给一篇与用户答案无关的范文。

## 九、结尾输出

最后给出：

1. 答案/结论速查表；
2. 本次最重要的 1—3 个知识遗漏或答题思维问题；
3. 下一次做题前的检查清单；
4. 24—48 小时后的闭卷复现动作；
5. **拟沉淀内容（尚未保存）**：知识卡、易混卡、用户错误模式和待核实冲突。

默认不自动写文件。只有用户明确说“确认保存/保存这次政治复盘/更新政治知识库”后，才允许落盘。

## 十、完整第一版输出结构（阶段一强制合同）

单题可压缩，但不得删除适用标题；章节、成组题或整套题必须按下列顺序形成可独立复习的第一版成品：

1. **本次范围、资料与版本核对**：来源、年份、STATIC/SYLLABUS/CURRENT/PREDICTION、题号、显式题目/小问分母、缺口与冲突。肖秀荣提纲、教材/讲义示例、材料案例和老师示范默认只作隐式证据，不进入题目分母或逐例展开，除非用户明确点名。
2. **肖秀荣提纲范围与本范围知识体系总览**：章节/专题整理先给出手册实际章节名、栏目、页码、知识块和跨章/缺口；再按真实内容组织理论、概念边界、史纲时间线、地位词、时政或材料映射框架。单题且不涉及提纲核对时可注明不适用。
3. **核心知识、重点与难点讲解**：知识点/原理 → 正式依据 → 材料或题目案例 → 边界 → 做题方法 → 易错点；隐式示例只贡献归纳后的方法，不显示逐例解析。
4. **提纲二级结论、易错辨析与隐藏限制**：整理肖秀荣手册中的注意、易错、辨析、记忆提示、跨章联系和年度/版本差异；尤其核对地位词、主体、时间、范围、充分必要关系和年度边界。
5. **全题登记与跨资料统一题型池**：把本范围真题、肖秀荣1000题、肖八肖四及其他指定题集统一登记。每题只有一个主题型，可附理论/史实对象、题干限定词、概念边界、材料映射、干扰项机制、分析题组织和版本性质等次级标签；不能按每本资料另建分类。
6. **题型整理结论与迁移表**：逐个主题型先给题干信号、优先核对内容、规范结论、排除/组织方法、适用边界、常见变式和全部关联题号。
7. **答案与考点速查表**：按原资料和原题号顺序列已登记主题型、AI 初判、最终答案、置信度、解析对照和修正状态。
8. **逐题/逐问完整解析**：按原资料顺序解析；选择题覆盖 A—D，分析题覆盖原理、材料映射、分点答案、主题型回扣和用户答案修正。
9. **解析省略与冲突处理**：分列题册/解析、正式材料、AI 初判、重新核验、最终采用和理由。
10. **错误分层与复现动作**：Level 1/2/3、标签、24—48 小时复现；没有真实用户证据时明确留空个人画像。
11. **最终压缩总结与覆盖审计**：证明显式题目登记数、主题型归类数和详解数一致；同时检查题号和小问、肖秀荣提纲应覆盖/已覆盖范围、版本边界、待核验分类、权威核验、AI 修正和未解决缺口。
12. **拟沉淀内容（尚未保存）**：知识卡、概念边界、统一题型方法、真实用户错误和待核实项。

阶段一完成后必须停止在“待用户验收”。长正文可按 `review-artifact-protocol.md` 在同一任务内连续分段，但只有最后一段可附总段清单、覆盖审计和验收询问；中间段的“继续”不构成确认或归档授权。不得直接把卡片或摘要写入知识库。
