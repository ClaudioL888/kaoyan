# 肖秀荣背诵提纲章节整理协议

本协议只在政治章节、专题、背诵提纲或知识大纲整理时强制使用。普通单题问答仅在相关表述需要核对时读取命中页。

## 1. 资料身份与优先级

- 唯一背诵提纲母本为 `政治\26肖背诵手册\26肖背诵手册.pdf`；涉及附录第 93 页时使用已补全版本。
- 肖秀荣背诵手册是老师整理的复习资料，不是官方大纲、权威教材或正式时政文件。
- 真题、正式材料、官方大纲和权威教材负责裁定事实、年度口径和规范表述；背诵手册负责提供复习结构、记忆重点、易混边界和命题提示。

## 2. 先冻结真实范围

1. 读取封面/版本信息、目录和目标章节首尾页，记录实际栏目名、印刷页与 PDF 页。
2. 按手册真实目录和知识对象定义范围，不凭通用教材章号、记忆或其他老师资料猜测。
3. 输出范围台账：章节/栏目、起止页、知识块、跨章关联、缺页或扫描/OCR 缺口。
4. 扫描 PDF 的目录、标题、表格、框注和关键政治表述必须视觉复核；OCR 只能用于定位，不能单独作为精确表述证据。

## 3. 必须提取的高价值内容

- 目录层级、知识框架、章节导语、复习提示和重难点；
- 定义、原理、地位词、主体—任务—目标—保障等固定搭配；
- 条件、例外、时间线、因果链、上下位与相近概念边界；
- “注意、易错、辨析、拓展、命题点、记忆提示”等功能性栏目，保留资料实际栏目名；
- 表格、时间轴、结构图、口诀及其适用边界；
- 典型真题、材料映射或分析题表达，但不能把预测题当成命题结论；
- 章末总结、复现问题和跨章联系。

不能整段照抄手册。以结构化转述、必要的短语级精确表述和来源定位为主。

## 4. 规范与年度核验

- 标记 `提纲稳定内容`、`地位词/规范表述待核验`、`年度/版本边界`、`官方来源已核验` 或 `页面未核验`。
- 若主体、时间、地位词、条件、范围或结论与更高优先级来源冲突，并列依据并采用更高优先级来源；不得静默改写提纲，也不得为迁就手册覆盖正式依据。
- 页面缺失、扫描不清或缺少裁定来源时写“未核验”，不补猜。

## 5. 章节第一版必须增加的内容

1. 肖秀荣手册版本、实际章节名与页码核对；
2. 章节知识大纲和知识块范围表；
3. 核心知识、二级结论、隐藏限制与跨章联系；
4. 易错、注意、辨析、记忆表达及适用边界；
5. 年度差异、规范表述和更高优先级来源核验；
6. 题型识别、材料映射和迁移；
7. “提纲应覆盖/已覆盖/仍未核验”的覆盖审计。

没有题册或用户作答时，不虚构答案表、错题诊断或个人薄弱点；相应栏目写“本次无题目/无用户作答证据”。

## 6. 保存边界

- 阶段一只在对话中输出，停止在用户验收；不得因已读完提纲而自动写入知识库。
- 用户同时确认内容准确且同意归档后，才把已接受正文写入模块 `reviews/`，并从中提炼可复用知识。
- 每条沉淀内容保留 `xiao_anchor`、版本、更高优先级核验来源（若有）、来源状态和记录时间。
