# 考研政治轻量知识库存储协议

## 固定目录

知识库根目录为 `E:\桌面\学习\考研\学习知识库\politics`：

```text
politics/
├─ catalog.json
├─ knowledge_cards.md
├─ concept_boundaries.md
├─ answer_methods.md
├─ user_weaknesses.md
└─ reviews/
   ├─ YYYY-MM-DD_HHmm_<subject-scope>.md
   └─ YYYY-MM-DD_HHmm_<subject-scope>.review-manifest.json
```

`catalog.json` 保存 `schema_version`、`subject`、`updated_at` 和 `accepted_reviews`。每条记录包含唯一 `review_id`、资料性质、年份、学科、题型、范围、相对路径、接受时间和实际来源。

此外，`modules/` 按六个政治学科预建目录，每个模块含 `module.json`、`knowledge_cards.md`、`concept_boundaries.md`、`answer_methods.md`、`user_weaknesses.md` 和 `reviews/`。`organization_status: skeleton` 只表示可路由，不是完成状态；时政模块尤其不得把空框架或旧年度条目当成当前事实。

## 单题课程内容增量

单道选择题、一个分析题小问、一个概念边界或一次材料映射问答，可以在双重确认后直接增量更新汇总文件，不要求新建完整 review。回答末尾的归纳至少包含：学科/题型/范围、STATIC/SYLLABUS/CURRENT/PREDICTION、年份或核验日期、核心结论、概念边界、材料或选项依据、答题方法、错误层级、建议归档、拟写入内容、`归并判定（预判）`和`拟归并目标`。

归纳还必须包含 `掌握度判断：当前掌握信号 / 候选薄弱点（待确认） / 已确认薄弱点 / 无法判断`。用户主动给出正确原理、史实、地位词或材料映射，只能证明本轮表述正确；不能自动写成“已掌握/不薄弱”，也不能直接写成个人薄弱点。结合是否能说明条件、依据和相近概念边界，以及是否存在猜测、犹豫、自我纠正、反复确认、矛盾或提示依赖来判断。

证据不足时先询问这是已掌握后的总结，还是仍易混淆且希望记录的薄弱点。候选状态不得落盘；用户答复后先更新完整归纳，再重新取得准确性认可和归档授权。

只有用户同时认可归纳准确并同意归档才可写入。只确认准确、只说保存、修改归纳、继续讨论或沉默均不写入；修正后必须重新展示完整归纳并再次确认。

- 稳定理论、史实或经核验时政 → `knowledge_cards.md`。
- 地位词、相近概念、上下位和条件差异 → `concept_boundaries.md`。
- 审题、逐项判断、材料映射与答案组织 → `answer_methods.md`。
- 有真实作答证据的遗漏、决策错误或用户明确确认的薄弱点 → `user_weaknesses.md`。主动正确结论和候选薄弱点均不能直接写入。
- 无新增价值 → 不写入；已有等价内容不重复知识正文，只有当前题提供更典型选项、材料、真题或权威来源且归纳已明确时，才补短引用。
- 单题增量不新建或改写 `reviews/`；CURRENT/PREDICTION 必须保留日期和来源性质。
- 单题增量优先写入命中的模块文件并将 `confirmed_increment_count` 加一；原有根目录汇总文件继续作为兼容索引和去重参考。单题、单卡或少量增量不得把模块升级为 `organized`。

## 内容映射

- 稳定理论、史纲事实、正式时政事实 → `knowledge_cards.md`，并标记 STATIC/SYLLABUS/CURRENT、年份和来源状态。
- 地位词、相近概念、上下位与条件边界 → `concept_boundaries.md`。
- 审题、逐项判断、材料映射和答案组织规则 → `answer_methods.md`。
- 用户真实错误、犹豫、错误理由、反复追问或自述 → `user_weaknesses.md`。
- 已接受的完整复盘正文 → `reviews/`。

同一内容不完整复制到多个汇总文件；使用题号和 review 相对路径建立短引用。

## 相近内容五态归并门

单题增量和完整复盘派生条目都必须检索命中模块及必要的相邻模块。比较理论/史实对象、主体、时间、地位词、范围、条件、上下位与相近概念边界、材料映射、题干限定词和答案组织；不能仅因主题、价值方向或关键词相同就归并。`STATIC / SYLLABUS / CURRENT / PREDICTION` 先分层，不同年度 CURRENT/PREDICTION 不得并入 STATIC 条目。

1. **等价**：规范结论、条件和答题规则实质相同，不新建；若本题提供更典型选项、材料、真题或权威来源，只给原条目补短题号/review 引用和 `引用补充时间`。引用补充不算新知识，不登记活动日志。
2. **补充**：同一知识/边界/方法但增加主体、时间、地位词、条件、反例、材料映射或答案组织，直接扩充原条目；保留原记录时间，新部分写 `补充记录时间`、资料性质、日期和题号。
3. **相邻**：属于同一理论簇、史纲事件链、概念边界组或答题方法池但不能合成同一结论，在已有父标题下建立子条目并短链相关项；不得建立孤立题号标题。
4. **冲突**：主体、时间、地位词、范围、概念边界、时政口径或材料结论不一致，在最相关条目下并列旧/新表述、STATIC/SYLLABUS/CURRENT/PREDICTION、来源、日期、题号和待核验/采用状态，不覆盖旧内容。
5. **全新**：完成命中及相邻模块检索后确无合适知识簇或方法池，才新建可迁移的顶层条目。

`无需新增` 用于无迁移价值、只是价值判断、预测未核实或证据不足。一个问题产生知识卡、概念边界、答题方法和真实个人弱点时分别判定；个人弱点只进 `user_weaknesses.md`，重复错误应扩充原弱点记录并保留每次用户证据。跨模块存在规范主条目时只保留一个主条目，其他模块用短引用，不全文复制。

预判和拟归并目标必须先向用户展示。双重确认后的复核若改变归并类别、目标、资料性质或拟写入内容，必须展示修订后的完整归纳并重新确认。

## 完整复盘保存顺序

1. 确认用户同时认可当前“阶段一完整第一版”及末尾归纳的准确性，并明确同意归档；答案表、知识卡草案、局部解析、单独的“准确”或单独的“保存”都不能替代完整第一版和双重确认。
2. 生成唯一 review 文件名；同分钟重名时追加序号，不覆盖历史文件。
3. 以已接受正文为阶段二唯一内容母本。完整读取并执行 [review-artifact-protocol.md](review-artifact-protocol.md)：恢复单段或全部已验收传输段，先取得逐段规范化正文哈希，再按段序拼成一个 review Markdown，并生成相邻 `.review-manifest.json`。只去掉正文边界外的聊天寒暄；BEGIN/END 之间的正文不得删改，拟沉淀部分即使不参与派生归并也保留在 accepted review 中。写后验证逐段及 assembled 哈希；原文不可取得时停止并报告归档正文缺口，禁止摘要重建。
4. 对每个派生逻辑项执行上述五态归并后更新相应汇总文件；只有真实用户证据才能更新 `user_weaknesses.md`。
5. 更新并解析验证 `catalog.json` 与 review manifest，检查 review/manifest 路径以及 `review_id`、路径唯一性。
6. 重新读取新增内容，报告写入路径、每项实际归并状态、主条目、增加的题号引用/补充段落、版本边界和待核实项。

肖秀荣提纲章节/专题复盘归档时，每个知识条目或范围块还要保留肖秀荣定位、手册版本、来源状态以及更高优先级核验来源（若有）。表述冲突和年度差异应并存并标为待核验，不能在归档时静默合并。模块内的 `outline_framework.md` 只有在已接受正文中存在对应证据时才按增量填充，空框架本身不计为新增知识。

成组、专题范围或整套复盘不得绕过完整第一版直接从题册、解析、讲义、旧知识库或记忆重建并保存；若当前对话缺少已接受正文，先索要正文或文件。单题增量只能来自当前已完整回答、已展示具体归纳且获得双重确认的内容，不得用它规避应当完整覆盖的复盘范围。

## 禁止事项

- 未确认时写入。
- 把预测题、转载大纲或老师概括标为官方事实。
- 用新结论删除旧复盘；年度变化或冲突应并存并标记日期。
- 把通用陷阱写成个人画像。

## 时间字段与活动日志

- 每个实际新增逻辑条目写 `记录时间：YYYY-MM-DD HH:mm:ss +08:00`，元数据写 ISO `recorded_at`，固定 `time_zone: Asia/Shanghai`（中国标准时间）。
- 每份完整 review/addendum 追加且只追加一条 accepted-review 容器记录，以 `derived_record_ids` 关联真实派生记录；每个派生 Markdown 条目自身写完整时间。
- 写入与复读验证成功后，向 `E:\桌面\学习\考研\学习知识库\activity_log.jsonl` 追加一行，保留政治模块、题型/题号、STATIC/SYLLABUS/CURRENT/PREDICTION、来源年份或核验日期、核心摘要和源文件。
- accepted review 与派生知识卡/边界/方法应语义去重，周期汇总不得重复计算同一条内容。
- 未双重确认、未成功落盘、已有等价内容和候选薄弱点不登记；时政日期与归档时间分列。
- 等价条目仅补题号/review 引用时，不增加 `confirmed_increment_count`，不登记活动日志；补充、相邻、冲突或全新形成实际逻辑增量时才按增量计数。
