# 408 章节复盘完整第一版与后续整理合同

本合同只用于章、节、连续题号或批量复盘；普通单题答疑不强制套用全部结构。

## 两阶段关系

1. 阶段一先在对话中形成一份可独立复习的完整成品。
2. 阶段一成品是阶段二整理的唯一内容母本。预检、答案表、题号清单、摘要、结构化字段或拟沉淀清单都不能替代它。
3. 只有用户明确验收阶段一并指定保存位置后，才可进入阶段二：先原样归档已接受正文，再提炼知识、题型方法和真实个人错误。
4. 阶段二不得绕过阶段一重新扫描 PDF 生成替代成品，不得暗改、缩写或覆盖用户已接受的正文。
5. 分批时，每批都要完成当前范围的完整适用结构；最后再形成总覆盖审计和跨批总结。既有 accepted 范围的纯分类追补只有在每题/小问完整详解均可直接定位时才能整章超限建立索引；详解正文缺失时必须按安全连续批次恢复，不能用摘要替代。
6. 阶段二写入前保存或取得已接受正文的规范化哈希/逐行基线；归档后必须验证正文一致。无法取得原文时停止并登记归档缺口，不生成“完整复盘”替代品。

## 长正文传输分段

受单次输出长度限制时，可按 [review-artifact-protocol.md](review-artifact-protocol.md) 在同一任务中连续分段。传输分段只切分会话载荷，不改变本合同的17项结构，也不等于题量安全批次。每段使用同一 `dossier_id` 和明确正文边界；中间段不得请求归档，最后一段必须给出段清单、总覆盖审计和待确认归纳。用户双重确认后，阶段二先将选定段按原序拼成一个 review Markdown 并生成相邻 manifest，再进行任何知识归并。

## 框架预留与实际填充边界

本文件同时定义未来章节复盘应具备的栏目，但“预留框架”不等于现在生产内容。

1. 预建 408 章节时，只创建章节元数据、空知识文件和 `chapter_framework.md` 的标题/空表格；不扫描或 OCR 教材，不提取考纲、知识框架、提示框和章末内容，不回答章首问题，不进行思维拓展分析。
2. 预留框架属于结构性元数据，不是课程新增，不写入 `activity_log.jsonl`，不增加 `confirmed_increment_count`，也不把 `organization_status: skeleton` 升级为已整理。
3. 只有用户日后明确指定一个实际章节、节或连续题号进行复盘时，才执行后文的完整成品结构并读取该范围来源。
4. 阶段一只在对话中形成完整成品；用户验收并授权保存后，阶段二才把已接受内容填入该章框架、知识文件和复盘归档。
5. 单题问答只处理当前问题。即使它对应某个预留栏目，也只能在双重确认后追加该条增量，不能借此补写未核验的章首或章末内容。

## 阶段二的相近内容归并门

阶段一归档正文保持完整且不可覆盖；从正文派生到教材知识、题型方法和真实个人弱点的每个逻辑项，必须按 [knowledge-protocol.md](knowledge-protocol.md) 的 `等价 / 补充 / 相邻 / 冲突 / 全新` 五态归并，另允许 `无需新增`。不得把一批题机械拆成一批孤立条目。

- 数据结构按算法模型、状态/不变量、操作和复杂度归入题型池；计组按字段/位宽、数据通路和时序归并；操作系统按对象、队列/资源状态、PV/地址时间线归并；计网按封装、地址、表项和逐跳过程归并。
- 等价题只补必要的代表题引用；补充内容扩充原条目；相邻内容进入同一父标题下的子条目；冲突并列保留；确无相近池才新建顶层条目。
- 预判类别和拟归并目标必须出现在阶段一末尾归纳中。阶段二复核若改变类别、目标或拟写入内容，必须重新展示修订归纳并取得准确性与归档双重确认。

## 教材导学、提示框与章末回扣证据层

章节复盘不能只抽取正文知识和习题。先识别教材从章首到章末承担教学功能的全部栏目；不同书名可能不同，按功能归类但保留教材实际栏目名、印刷页/PDF 页和来源状态。

1. **章首导学：**提取考纲内容/考试要求、知识框架/知识地图、复习提示/学习建议、学习目标、重难点提示、章首导语，以及章首先行提出的问题。不得把考纲条目直接扩写成教材结论；要标出教材覆盖位置和本章复习优先级。
2. **章首问题台账：**逐条记录“原问题摘要—提出位置—正文对应小节—章末是否明确回答—最终回答”。教材有明确回答时忠实整理；只有隐含材料或没有答案时，写“AI 分析”，列出依据、推理和不确定性，不能冒充教材原答。
3. **正文提示框：**识别“注意、提示、特别提醒、说明、补充、辨析、易错、考点、方法、结论、拓展”等同功能栏目和页边批注。对每条判断它属于定义条件、例外、边界、经验口诀、操作步骤还是易错反例，并说明可迁移题型；不得只抄框中文字。
4. **章末收束：**完整检查本节小结、本章小结、归纳总结、知识框架回看、疑难点、常见问题、自测问题、思考题和思维拓展。章末内容要与章首考纲、知识框架和问题台账逐项对照，指出已闭环、部分闭环和未回答项。
5. **思维拓展：**若教材给出明确结论，区分教材事实和解释；若只给开放问题，直接做 AI 分析，但必须写清假设、机制、反例或边界、与 408 考试的关系，不把开放讨论伪装成必考结论。
6. **覆盖要求：**固定给出“章首栏目—正文提示框—章末栏目覆盖表”。某类栏目经逐页核对不存在时写“教材本章未设置/本轮未发现”；不能因栏目名称不同或不在目录书签中而静默遗漏。

## 阶段一完整成品的固定组成

以下标题必须按顺序出现。某项经核对确实不适用时，保留标题并说明原因，不得静默删除。

1. **资料、版本与范围核对**：教材、选择题本、应用题本、答案/解析的角色；印刷页/PDF页；题数、小问数、跳号、重复副本、损坏和版本冲突。
2. **章首导学与问题台账**：考纲内容、知识框架、复习提示、学习目标、重难点、章首问题及其预计回扣位置；保留教材实际栏目名。
3. **本范围知识体系总览**：按教材真实目录说明对象、核心机制/结构、基本操作/公式、典型过程、边界与易错点，并与章首框架对照。
4. **核心知识、重点与难点系统讲解**：知识点 → 教材依据 → 教材案例/图表/算法 → 原理或机制 → 做题方法 → 边界 → 题型识别。
5. **教材提示框、二级结论、隐藏重点和典型案例**：逐项整理注意/提示/说明/补充/辨析/易错/拓展、特别情况、小结、常用但未单独编号的方法和值得反复学习的案例。教材例题、算法案例、图示案例和讲义示范只隐式支持题型与方法总结，不显示逐例题号、题面或解析，也不进入显式题目分母，除非用户明确点名。
6. **重点难点易错点专项**：正确情况、错误情况/反例、真正判断条件、常见计算/状态/概念错误。
7. **全题登记与跨来源统一题型池**：先登记全部显式选择题、应用题和小问；跨教材习题册、专项题册、真题及其他指定题集统一分类。每题一个主题型和必要次级标签，先输出题型定义、识别信号、过程模型、优先方法、条件边界、复杂度/时序风险、难度变化和全部关联题号。四科主题型依据分别为：数据结构的对象/算法模型/状态不变量/操作/复杂度，计组的数据表示/字段位宽/数据通路/控制时序/性能，操作系统的对象/状态队列/资源/PV调度地址I/O过程，计网的层次协议/报文/地址/表项/逐跳时序/性能。
8. **选择题答案速查表**：按原题号列已登记主题型、最终答案、来源对照和冲突状态。
9. **选择题逐题完整解析**：按原题册顺序给完整题干和全部选项；A—D 逐项判断；组合题先判 I/II/III/IV；给教材/解析依据、独立推导、第一反应、主题型回扣和易错点。
10. **应用题答案/结论速查表**：每题及全部小问分别列已登记主题型、最终结果或待证结论。
11. **应用题逐题完整解析**：按原题册顺序给完整题面、输入/已知、模型/算法、关键状态或时序、必要伪代码/公式、每问结论、主题型回扣、复杂度/单位/边界检查和条件变化后的迁移。
12. **解析省略与资料冲突处理**：题册答案、正式解析、教材依据、独立推导、最终采用和理由；不得迎合错误答案。
13. **题型识别与教材—题目迁移表**：基于第7项统一题型池，汇总题目信号、第一反应、优先方法、教材案例的隐式支持、过程表示、复杂度/边界和代表题号；不得另建冲突分类。
14. **章末归纳、疑难点、思维拓展与章首回扣**：整理教材章末栏目；逐条回答章首问题；开放项做有标识的 AI 分析；报告闭环状态。
15. **最终压缩总结**：必须掌握的定义/机制/公式/算法，最值得复习的教材案例所支持的方法，高频套路，最重要错误和 3—8 个闭卷自测问题；隐式案例仍不逐例展开。
16. **题目—知识点—主题型对应表与覆盖审计**：核对显式题目登记数、主题型归类数和详解数一致；同时检查题号、小问、选项、章首/提示框/章末栏目覆盖，来源状态、AI 修正记录、待核验分类和未解决缺口。
17. **拟沉淀内容（尚未保存）**：教材知识、统一题型方法、真实用户错误和待核实冲突；每个逻辑项附 `归并判定（预判）` 与 `拟归并目标`。

四科专项提示词负责把“关键状态或过程”具体化：数据结构用指针/数组/树图状态，计组用字段/位宽/时序，操作系统用信号量/队列/资源状态，计网用拓扑/地址表/逐跳时序。

阶段一完成后停在“待用户验收”。阶段二使用本合同、`review-artifact-protocol.md` 与 `knowledge-protocol.md`；没有明确确认和指定保存位置时，不写任何整理文件。
