# 408 科目路由与专项规则

## 科目识别

先根据题目对象判断具体科目，不要求用户手动标注。

| 科目 | 常见识别信号 |
|---|---|
| 数据结构 | 线性表、链表、栈、队列、字符串、KMP、树、二叉树、图、查找、排序、算法复杂度 |
| 计算机组成原理 | 补码、浮点数、CPU、CPI、指令、寻址、数据通路、流水线、Cache、TLB、总线、I/O、DMA |
| 操作系统 | 进程、线程、调度、信号量、P/V、死锁、内存管理、页面置换、文件系统、设备管理 |
| 计算机网络 | OSI、TCP/IP、以太网、CRC、ARP、IP、CIDR、路由、NAT、TCP、UDP、DNS、HTTP |

若一道综合题同时涉及计组和操作系统（例如 TLB、页表、Cache），按题目真正设问分别处理各小问，不把整题强行归入单一科目。

## 四科单题最低要求

### 数据结构

- 给出输入、输出、结构状态、核心算法和边界。
- 算法题写明循环/递归终止条件、关键不变量、时间和空间复杂度。
- 逐步展示栈、队列、指针、访问序列、数组或树形态的必要变化。
- 检查空表、单结点、首尾、满队列、重复关键字、下标和稳定性。

### 计算机组成原理

- 先列公式、变量、单位和适用条件，再代入。
- 地址题拆出页号/块号/组号/标记/偏移等字段并说明位宽。
- Cache、TLB、页表、主存和虚拟存储不得混为一层。
- CPU 性能、流水线和 I/O 题保留关键时序及数量级检查。

### 操作系统

- PV 题先定义每个信号量的语义和初值，再写 P/V 位置。
- 调度题画时间线；页面置换题列页框状态和缺页次数。
- 死锁题说明资源状态、安全性和阻塞/唤醒条件。
- 地址转换和文件系统题保留页表、块号、索引或访问过程。

### 计算机网络

- 先读拓扑并标出接口、网络边界、IP、掩码和网关。
- 分开处理 ARP 缓存、交换机转发表、路由表和 NAT 表。
- 逐跳说明源/目的 MAC 与源/目的 IP 的变化。
- TCP 题列序号、确认号、窗口、丢包/重传和状态；时延题核对单位和公式。

## 错因诊断

每个真实用户错误可从以下层次诊断：

1. 概念或公式不会；
2. 知道概念但适用条件/边界混淆；
3. 结构识别错误，选错方法；
4. 计算、单位、下标、状态或顺序错误；
5. 题干/图表/小问读取不完整；
6. 时间压力或无意义机械展开。

结尾给出一条可执行规则和一个复现动作。未经用户真实证据，不写成个人弱点。
