# 22408个人考研心得与做题协议

**版本**：V2.1（数学章节节奏与线代强化明确版，2026-08-21）  
**性质**：只细化已有资料的做题和看课方法；不增加题源、老师、章节或学习时长。

## 1. 数学二：五分钟诊断—整理—重写

1. 每道张宇1000 B组题先计时 **5 分钟**，只判断是否找到可靠入口。
2. 有思路并能写下去：继续独立完成，记录实际用时。
3. 无入口：直接看答案/解析，不进行无效试错。
4. 看答案只整理：题型入口、关键条件/定理、自己的卡点。
5. 合上答案，用自己的步骤立刻重写；不能把“看懂”当完成。
6. 下一数学日开头用10—15分钟整理前一章：只登记题号、题型入口、关键条件和错因；错/犹豫/计算错题进入A组，不全量机械重做。
7. 标记为独立完成、提示后完成、看答案后重写、计算错或暂未掌握；D+2、D+7闭卷重做A组暴露题。

五分钟是“是否继续盲试”的诊断线，不是证明题和综合题的最终作答限时。高数每章按1—2个数学日完成强化主推进，次日按第6步短整理，章节收口再做一次限时/证明/计算输出；未覆盖题号保留到后续整理。高数 B15 收口后，线代 B1—B9执行同一节奏。A组只回炉错/犹豫/计算错；B组是主线；C组是后置四套综合模拟。

## 2. 408：每章的强化闭环

```text
闭卷框架
→ 课本＋选择题梳理
→ 按需强化课
→ 应用题思路与得分点
→ 合上答案独立完成
→ D+2 / D+7 / D+21
```

### 具体动作

1. 先闭卷写 10—15 分钟本章框架，再对照王道课本补定义、条件、公式、流程和边界。
2. 选择题一轮已做，只重做错、犹豫、猜对、计算/过程题；每题写错因和下次判断规则。
3. 只有框架或薄弱点需要补时，才看当前章强化课。单日约 45—75 分钟，嵌入既有 408 主块，不追全套视频。
4. 对应用题先自己写结构；再看答案，整理识别条件、步骤、得分点、边界；合上答案独立写一份标准答案。
5. 用 AI 检查答案遗漏、解释差异或比较方法；AI 不得替代自己闭卷输出。
6. 每章建立题型表：题型名称、识别条件、标准步骤、常见陷阱、代表题号、复现日期。

每章强化只占 1—3 个有效日：1 天章做一份代表输出，2/3 天章在后续日完成独立重写与题型表；绝不要求在强化期清空同质应用题。它们留给后续的 D+2/D+7/D+21、应用题二轮和真题。

### 四科独立答案骨架

- 数据结构：数据结构→不变量→算法思想→边界→C/C++代码→时空复杂度。
- 计组：数据表示/公式→状态变化→计算过程→单位检查→结论。
- OS：进程/资源关系→调度或地址转换步骤→结论；PV另写资源/事件、信号量含义、初值、临界区和依赖。
- 计网：分层协议→报文或时序→公式计算→边界→结论。

算法/PV只在触发章节完成基本框架后使用 D0、D+2、D+7、D+21；未触发时做当前章应用题。
