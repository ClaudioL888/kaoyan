# 22408题量、难度与人类耗时评估

**版本**：V2.1（数学章节节奏与线代强化明确版，2026-08-21）  
**用途**：校准主计划的真实工作量；本文件是“章节预算和减负”依据，不新增教材、老师或题源。

## 0. 评估口径

- 估算包含：独立尝试、订正、错因记录和一次必要的闭卷输出；不包含长时间看课、走神和重复抄解析。
- 你数学基础较好且张宇1000基础篇已过，因此数学按“会做题的强化首刷”估算；408按“一轮浅、二轮需要输出”估算。
- 题量很大时，计划按章节预算工时推进，不用日历强行清空；未完成章节顺延。
- “完成一章”不是看完答案，而是完成高价值题、薄弱题订正和一次闭卷输出。

### 1.3 数学执行结论

- 每天数学块约2小时45分钟时，450题完整首刷不可能在两周完成，现实周期约6—8周；这不代表每天必须做固定题数。
- B组是强化主线；A组只回炉已做过的错题、犹豫题、计算错误题；C组后置到B组和数学专题真题之后。
- 章节完成标准：B组当前章完成到足以覆盖主要题型 + A组薄弱题回炉 + 一次限时/证明/计算输出。偏难低频题可登记后延，不用吞噬当天全部时间。
- 高数“每章1—2天”定义为强化主推进，不把本表的题量、预计工时或未覆盖题号删去：下一数学日先做10—15分钟前一章整理，D+2/D+7回炉暴露题，章节收口再补限时输出。高数 B15 后，线代 B1—B9按相同规则形成明确的独立强化阶段。

### 2.3 408完成标准

本节上方的 185—252 小时级预算，指“选择题梳理＋薄弱题＋高价值应用题”较完整地覆盖一遍的总工作量，不能塞进每章 1—3 天。现行计划把它拆成两层：**每章 1—3 天的强化建模**只交付框架、薄弱选择题、代表题型和一次独立输出；其余同质应用题、到期复现和真题订正放入 10 月 17 日起的第二轮。这样压缩的是首次建模期，不是把学习标准降为“看过”。

1. 先闭卷回忆章节框架，再快速梳理全部选择题。
2. 只重做错、犹豫、猜对和计算/过程题；每题记录错因、边界和下次规则。
3. 应用题按“代表题型优先”：数据结构写不变量/边界/代码/复杂度；PV写资源事件、信号量含义、初值、临界区和依赖；计组/计网写完整计算或协议时序。
4. D0首次输出，D+2闭卷重写，D+7改条件，D+21混合抽查。不是把所有同质题当天清空。

## 3. 英语二阅读

- 你六级550、高考133，英语不需要用大量模拟阅读堆量；英语二真题优先。
- 一篇阅读：限时15—20分钟 + 原文定位20—30分钟 + 逐项选项/长难句/词汇复盘25—40分钟，合计约60—90分钟；加每日词汇25—30分钟，阅读日总量约85—110分钟。
- 8—9月固定每周5篇阅读；其余日做词汇30分钟和旧文错题/长难句30—45分钟。不新增英语一硬指标，不提前消耗最近3套英二真题。
- 完成标准是形成“定位句、同义替换、干扰项类型、错因标签”记录，而不是只统计对了几道。

## 4. 政治

- 现阶段使用强化讲义/课程 + 对应基础选择题；每天新内容45—70分钟（理解20—30，题目15—25，错因10—15）。
- 每周5天新内容、1天全周错题/框架复盘、1天弹性休息或补缺；暑期不背分析题。
- 你理解力和背诵意愿较好，政治前期不应挤占数学/408的核心块；10月后再逐步增加选择题二轮和分析题提纲，11—12月再进入集中背诵。

## 6. 调整闸门

- 数学某章连续两天只能完成同质题或正确率低于70%：停下扩张，回30讲/该章A组薄弱题和错题；不进入C组。
- 408当前章超过预算上限仍未掌握：保留未完成题号，先进入下一日的同一章，不为赶周表跳章。
- 算法/PV首次闭卷完成率低于70%：下一次减少新题，执行D+2/D+7重写；不提前扩展到未学章节。
- 英语阅读连续两周稳定且错因不在词汇：维持每周5篇，不增加数量；若政治新内容压缩到45分钟仍能完成，则不额外加时。
